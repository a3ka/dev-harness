# Слово владельца 2026-10-03: каналы норм, инструменты, генераторы, done

## 1. Принцип
Код делает то, что повторяется с известным ответом; модель — суждение, конструкцию,
развилку, судейство. Класс нормы определяет канал ПРОВОДКИ:
- процедура → tool (scripts/<инструмент> + role-строка вызова): инструмент выполняет вместо агента;
- отказ → guard (scripts/<барьер>);
- суждение/поведение → role (roles/<роль>.md);
- устав → charter (AGENTS.md);
- два артефакта обязаны совпадать → один генерируется из другого (генератор).
Норма класса «процедура», проведённая только role-каналом, — отказ pre_critic
«процедура без инструмента». Инструмент обязан иметь красную клетку «делает заявленное».
Источник кандидатов — замер: шаблоны действий агентов, повторённые > N раз за неделю
(замер 2026-09-30..10-03: из 2129 bash ведущей сессии ~1300 — снятие состояния:
git 441, детектор 318, gh CI 239, fetch 169; субагенты Mint/Obs/Fix* — механика).

   предупреждений;
7. документация (CHANGELOG/README/ADR) при изменении поведения;
8. issue закрыт со ссылкой на PR; поля проекта «Odelix Delivery» обновлены; blocked-by
   закрыты до старта;
