# Консультант санкционирует один узкий повторный вызов судьи на задачу без слова владельца

дата: 2026-11-24
вопрос: ночью 23–24.11 три предмета (210, 152, 189) стояли до утра на одном классе вопроса — «ещё один узкий судья на дельту санкционированного ремонта»; у консультанта было право только на узкие доп. вызовы критика (ADR 17.11), дополнительный adversary/reviewer — только словом владельца. Станция простояла 0/3 слотов несколько часов (отчёт СЛОТЫ 02:05).
решение: консультант вправе один раз на задачу санкционировать один узкий дополнительный вызов судьи любой роли (critic, adversary, reviewer) — только на дельту ремонта, который уже санкционирован словом владельца или самим консультантом в его праве. Запись — `sankcija-add.py` с причиной «право консультанта, ADR 2026-11-24» и OBJECT; FAIL узкого вызова → арбитр или остаточный риск словом владельца, второй узкий вызов по тому же праву не даётся. Расширение задачи, смена границы, правка frozen-текста, done без судьи — по-прежнему только словом владельца.
кто решил: владелец, 2026-11-24 ~12:10 UTC («5. да» на строку консультанта: «Постоянное право консультанта на один узкий повторный вызов судьи по задаче (предложение Fable). Сам себе его не присваивал — подтвердите отдельно.»).
основание: рекомендация Fable 24.11 (`FABLE-2411-ANSWER.md`, блок 3: «три из девяти ночных вопросов — один класс; постоянное право консультанта на один такой вызов на предмет сняло бы ночные простои»).
область: станция и все проектные сессии.
рассмотренные варианты: (а) прежний порядок — каждый доп. adversary/reviewer словом владельца — отвергнуто: ночные простои; (б) право без ограничения числа — отвергнуто: обходит бюджет кругов `roles/critic.md §Быстрый-процесс`.
условие пересмотра: узкий вызов по этому праву, после которого задача ушла в арбитраж по спору о границе дельты.
статус: принято (слово владельца 2026-11-24)
