# Канал нормы по её классу; процедуры — инструментами, совпадения — генераторами

дата: 2026-10-03
вопрос: чем исполняется каждая норма — текстом роли или кодом
решение: код делает то, что повторяется с известным ответом; модель — суждение,
  конструкцию, развилку, судейство. Канал ПРОВОДКИ по классу нормы:
  процедура → tool (scripts/<инструмент> + role-строка вызова); отказ → guard
  (scripts/<барьер>); суждение/поведение → role (roles/<роль>.md); устав → charter
  (AGENTS.md); два артефакта обязаны совпадать → генератор. Норма класса «процедура»,
  проведённая только role-каналом, — отказ pre_critic «процедура без инструмента».
  Инструмент обязан иметь красную клетку «делает заявленное». Кандидаты — по замеру:
  действия, повторённые > N раз за неделю.
  Пачка 1 до V-2: orch_status.sh (состояние, --handoff), ci_wait.sh, pr_land.sh; строки
  роли: состояние — только orch_status, ожидание CI — только ci_wait, приземление — только
  pr_land, номер — только mint_line. Пачка 2 и генераторы (new_contract, заготовка
  батареи, мутанты, make_task, шаги CI, норма-строки ролей) — параллельно с V-2; make_task
  перенесён в II-3 (см. «контекст агентов»).
основание: слово владельца 2026-10-03; снимок §1–§3 (4e15d0d и далее).
  Замер 2026-09-30..10-03: из 2129 bash ведущей сессии ~1300 — снятие состояния
  (git 441, детектор 318, gh CI 239, fetch 169); субагенты Mint/Obs/Fix* — механика.
  Ручные ошибки той же механики: Н-71 (зоны по памяти ×3), Н-39 (забытая строка),
  ROADMAP с двумя порядками.
область: scripts/**, roles/**, AGENTS.md, scripts/pre_critic*, роль:orchestrator,
