# Что получает агент: каналы, слои, ContextPack v0

дата: 2026-10-03
вопрос: кто и как решает, что попадает в контекст каждого агента — на харнесе и на
  внешнем проекте (Odelix)
решение: каналы доставки — К1 промпт роли (генератор), К2 AGENTS.md репо (omp сам),
  К3 скил (процедуры, тело по требованию), К4 сборка задания make_task = ContextPack v0,
  К5 брифинг, К6 проверка (отказ с причиной), К7 ссылка (агент дочитывает сам). Правило:
  «всегда» → К1/К2; процедура → К3; зависит от задачи → К4 (+К7); проверяемое — ещё и К6.
  Пять слоёв с хозяевами: роль (владелец); карта проекта в профиле, включая rules: и
  карту reuse (архитектор при подключении, подпись владельца); контекст контракта —
  КОНТЕКСТ: и §Существующее в форме спеки §7.3 (Поиск / Исход: использовать · расширить ·
  выделить · создать · отложить / Владелец / Причина) — архитектор, форму проверяет
  pre_critic, полноту — критик; механическое (ЗОНА из frozen-блоба, decisions_for,
  lessons_for, вердикты, класс, бюджет, Н-39, правила зоны, шаблон модуля) — вычисляет
  make_task; дельта круга — единственный свободный текст оркестратора.
  Вклейка ~10–20K обязательного + манифест ссылок; потолок вклейки 40K → «режь задачу».
  Анти-дубль по структуре кода: карта репо зоны (tree-sitter + ранжирование) и
  lsp/grep-запросы в «Поиск:». Один механизм «по глобу» для ADR, правил кодинга, правил
  паков и уроков. Уроки — playbook (ОБЛАСТЬ, счётчик рецидивов, статус). Порядок в
  задании: стабильный префикс → изменчивый хвост. Трейс прочитанного → еженедельный отчёт.
  Ревьюер получает текст выданного задания. Параллельные исполнители — одинаковый блок
  решений и §Существующее. Паки C0–C3 — по боли; до них правила кодинга идут ключом
  rules: профиля (документы самого проекта, без копий).
основание: слово владельца 2026-10-03; снимок §12 (15265f9), §13 (468d2d6); ROADMAP
  e23dc3f.

рассмотренные варианты:
  - широкое окно у оркестратора со всеми документами проекта — отвергнуто: цена и
    деградация на длинном контексте; глубина нужна архитектору задачи, не диспетчеру;
  - пакет модуля 30–80K целиком в задание (§12.4) — заменено вклейкой + ссылками;
  - векторный индекс кода — отвергнуто: устаревает; LSP/grep/карта репо достаточны;
  - ждать D3 (Inventory/reuse preflight) — отвергнуто: V-2 стартует раньше.
условие пересмотра: отчёт по трейсу показывает, что агенты не читают ссылки и ошибаются
  без них, либо вклейка систематически упирается в 40K
