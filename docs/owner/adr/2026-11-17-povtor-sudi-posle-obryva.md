# Один повтор судьи после технического обрыва разрешает консультант, не владелец

дата: 2026-11-17
вопрос: кто разрешает повтор вызова судьи, оборвавшегося без вердикта по технической причине, если бесплатный повтор по 167 уже израсходован
решение: консультант вправе разрешить ровно ОДИН повтор на том же OBJECT сверх бюджета, если вызов завершился без вердикта по технической причине (обрыв/отказ или фильтр провайдера, неверная модель профиля, нет строки санкции в HANDOFF, противоречие инструкций изоляции, ошибка инструмента) и консультант проверил это по учёту замка и транскрипту. Не покрывает: новый круг после accept/FAIL, архитектуру, бюджет по существу. Полный текст правила — `docs/owner/2026-11-17-povtor-sudi-posle-obryva.md` (#1062).
кто решил: владелец, 2026-11-17 ~19:55 UTC: «ок» — на предложение консультанта «стоячее правило: я разрешаю один повтор, если вызов оборвался без вердикта по технической причине … Рекомендую дать, но только на обрывы.»
основание: 17.11 моб и бэкенд простояли ~3 ч на словах владельца, среди которых два — повторы после обрыва: моб 199 (Critic199V4 RELEASE `obryv_bez_verdikta` 15:06:32Z — не было строки санкции), бэкенд 185 (Critic185Narrow/Narrow2 `obryv_bez_verdikta` 16:39:55Z/16:43:07Z — профиль критика на GLM). Учёт: `…/complior-mob/state/zamok/uchet.jsonl`, `…/complior-back/state/zamok/uchet.jsonl`.
область: роль consultant; сессии (orchestrator) — строка СУД с проверкой консультанта до вызова.
рассмотренные варианты:
  - каждый повтор — словом владельца (как до 17.11) — отвергнуто: простой сессий при технических причинах;
  - разрешить повтор самой сессии — отвергнуто: сторона спора не проверяет собственный обрыв.
условие пересмотра: злоупотребление (повторы без проверки, повторы по существу) — отзыв словом владельца; учёт повторов — журнал консультанта.
