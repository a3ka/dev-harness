# Счёт «не более двух» узких вызовов критика — только вызовы, санкционированные консультантом сессии; для всех предметов

дата: 2026-11-18
вопрос: консультанты сессий читают предел п.1 ADR 2026-11-17 («не более ДВУХ таких вызовов на предмет») как счёт ВСЕХ вызовов критика по предмету — из-за этого почти каждый повторный узкий вызов после FAIL приходит владельцу, хотя по существу ответ всегда «да»
область: все предметы dev-harness, Complior-back, Complior-mob. Для экранных предметов Complior-mob то же уже записано в `docs/owner/adr/2026-11-18-ekrany-mob-byudzhet-sudov.md` п.1 — эта ADR распространяет правило счёта на остальные предметы; прочие пункты ADR экранов (основание от судьи реализации и др.) на другие предметы НЕ распространяются.
решение (уточняет только счёт п.1 ADR 2026-11-17; всё остальное — как там):
  1. «Не более ДВУХ таких вызовов на предмет» считает только вызовы критика, которые санкционировал консультант сессии по ADR 2026-11-17 (или по ADR экранов). Базовый фазовый бюджет `roles/critic.md §Быстрый-процесс` и вызовы по прямому слову владельца в этот счёт не входят.
  2. Условия вызова не меняются: прошлый вердикт — FAIL критика с конкретными блоками; дельта-лист закрывает именно эти блоки; дельта узкая; проверка — только эти блоки и зависимый регресс. Арбитраж не заменяется: после третьего вызова критика по предмету без accept санкция по этому счёту — только после арбитража о конечной границе (AGENTS.md §Арбитр, `roles/critic.md §Остановка`); арбитра созывает сессия без владельца (правило 15), узкий вызов на исполнение решения арбитра — по §Остановка.
  3. Остаётся владельцу: третий и дальнейший узкий вызов по счёту п.1; любой полный круг; архитектурный выбор; ослабление обязательств; смена класса риска; предметы старого порядка (заведённые до 2026-10-24 — там арбитр).
  4. Кап кругов `freeze_contract.sh` не снимается (третий и дальнейший круг — вердикт арбитра или строка `РАЗРЕШИЛ-ВЛАДЕЛЕЦ:` в причине заморозки).
  5. Запись санкции — как в ADR 2026-11-17, плюс номер вызова по п.1 этой ADR.
кто решил: владелец, 2026-11-18 ~18:20 UTC — «№12 — «да»» на вопрос консультанта (батч №3 №12): «считать ли „не более двух узких вызовов“ по ADR 17.11 только по вызовам самой ADR для всех предметов, а не только для экранов моба».
основание: 18.11 к владельцу пришли повторные узкие вызовы критика по 197, 095, 125, 187, 152 (батч №3 №1, 5, 6, 7, 8) — каждый после FAIL с 1–2 блоками, консультанты сессий рекомендовали «да», но не вправе были санкционировать по строгому счёту.
что не меняется: механизмы и двери, роли, устав, бюджеты ревьюера и адверсария, условия узкого вызова.
cognitive-only: механизма нет — счёт ведёт консультант сессии по записям СУД в HANDOFF; машина не ловит превышение счёта и санкцию без вердикта-основания. Кап кругов `freeze_contract.sh` серию FAIL→accept не ловит (подряд одинаковые классы сжимаются) — пропуск арбитража после третьего вызова машина не видит. Ловцы: ревьюер предмета по записи СУД, внешний консультант по журналу.
условие пересмотра: злоупотребление (санкции без дельта-листа, повтор причины, расширение «узкого» до полного) — отзыв словом владельца.
статус: принято (слово владельца 2026-11-18)
