# Роли проектных сессий пересеваются автоматически: сторож сверяет их с харнессом и просит мягкий перезапуск

дата: 2026-11-17
вопрос: как тексты ролей субагентов проектных сессий (бэкенд, моб) поспевают за правками ролей в харнессе, если сессии неделями не перезапускаются
решение: сторож `/root/reseed-nudge.sh` (tmux `consultant:reseed`, цикл 600 с) сверяет роли профиля проекта (`…/home/.omp/profiles/dev/agent/agents`) с `node scripts/gen-harness.ts --into` текущего харнесса; при расхождении просит сессию на чистом поле (нет живых субагентов и джобов, судей не обрывать) сделать чекпойнт HANDOFF/ROADMAP и последним действием `touch /tmp/dev-harness-verify/{back,mob}-restart`; back-loop/mob-loop перезапускают сессию через connect_project — workshop раскладывает свежие роли. Напоминание не чаще 2 ч. Вместе с ним: сторож загрузки `/root/load-nudge.sh` следит и за мобом (%2, норма 3).
кто решил: консультант по мандату владельца 2026-11-17: «Доделать автономность» (поручение дня) и «так ты начал работу над автономностью?».
основание: роли раскладываются только при старте (`workshop:975`, `gen-harness.ts --into`); бэкенд стартовал 15.11 (роли 08.11), моб — 16.11; расхождение с харнессом — 10 из 13 файлов (critic −58 строк, architect −56); модели читались живьём (`--config $HERE/.omp/config.yml`), тексты — нет. Проверка сторожа: свежее против свежего — 0 расхождений, устаревшее — 10.
область: сервер (`/root/reseed-nudge.sh`, `/root/load-nudge.sh`), `/home/harness/{back,mob}-loop.sh`; роль consultant; сессии проектов (orchestrator).
рассмотренные варианты:
  - перезапускать сессии вручную консультантом — отвергнуто: зависит от присутствия консультанта, ночью не случится;
  - класть роли в профиль без перезапуска — отвергнуто: omp читает агентов при старте, сеет только workshop.
условие пересмотра: workshop/omp начнут перечитывать роли без перезапуска сессии.
статус: принято (консультант по мандату владельца 2026-11-17)
