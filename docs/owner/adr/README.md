# Решения владельца 2026-10-03 — черновики ADR

Здесь записаны решения, принятые владельцем 2026-10-03 в работе с консультантом, и их
причины. Оркестратор в этом планировании не участвовал: эти файлы объясняют, ПОЧЕМУ план
стал таким, какой он в ROADMAP §11 и в снимке
`docs/owner/2026-10-03-done-i-instrumenty.md`.

## Статус и место

- Решения ПРИНЯТЫ словом владельца. Файлы — черновики по формату ADR (снимок §8.2).
- Лежат здесь, а не в `decisions/`: `scripts/check_decisions.sh` держит состав `decisions/`
  исключительным — «ровно файлы 001-007» на любой глубине; восьмой файл = красный
  `check:decisions` в CI и закрытые ворота судей.
- Номеров нет намеренно: номер выдаёт механизм (правило 5 устава), класса ADR в next_id
  ещё нет.
- Перенос — в II-3, пункт «ADR-минимум» (снимок §13.8): new_adr.sh выдаёт номер, кладёт
  файл в `decisions/`, check_decisions без пина «ровно семь». После переноса этот каталог
  удаляется коммитом по правилам check_protected, ссылки в ROADMAP/HANDOFF переводятся
  на номера.
- Правка этих файлов — только по слову владельца.

## Как читать

Каждый файл: дата, вопрос, решение, основание (боль с числами и коммиты), область
(пути и роли, на которые решение действует), рассмотренные варианты, условие пересмотра,
статус. Если твоя работа задевает область — решение действует для тебя.
