# Стоячее правило 2026-11-17: повтор судьи после технического обрыва — разрешает консультант

Запись слова владельца консультантом (канал владельца).

## Слово владельца

2026-11-17 ~19:55 UTC: «ок» — на предложение консультанта: «стоячее правило: я разрешаю один повтор, если вызов оборвался без вердикта по технической причине. Без него при каждом таком обрыве сессии снова будут вас ждать. Рекомендую дать, но только на обрывы.»

## Правило

Консультант вправе разрешить **ровно один** повторный вызов судьи (critic/adversary/reviewer/arbiter) **на том же OBJECT** сверх учтённого бюджета, если одновременно:

1. предыдущий вызов завершился **без вердикта** (в учёте замка `obryv_bez_verdikta` либо сессия судьи окончилась без коммита вердикта);
2. причина — **техническая**: обрыв/отказ провайдера, фильтр провайдера, неверная модель профиля, отсутствие строки санкции в HANDOFF, противоречие инструкций изоляции, ошибка инструмента;
3. консультант проверил 1–2 по учёту замка и транскрипту сессии судьи и записал проверку в санкцию (HANDOFF сессии, строка СУД).

Не покрывает (только слово владельца): новый круг после вердикта (accept/FAIL), смену OBJECT по существу, архитектурный выбор, выход за бюджет по содержанию, второй повтор того же вызова. Бесплатный повтор по контракту 167 (`--osvobodit`) применяется первым; это правило — следующий шаг, не замена.

Мера: число повторов по этому правилу и их исходы консультант ведёт в журнале плана; при злоупотреблении правило отзывается словом владельца.
