Пустое тело теперь выдаётся побайтово (ноль байтов stdout, curl rc0).

Пустые/неполные ответы — конформные входы отказного сценария API, не

### Механизм M11 и различающий вход

M11 — `|| total=-1` → `|| true` в `check_ci_gate.sh` (writer строка 117,
gate строка 200 OBJECT; ровно два вхождения, проверяется стабом). jq на
теле «валидный JSON + незавершённый хвост» печатает значение ПЕРВОГО
документа и лишь затем падает rc5 (замер на станции): присваивание
получает частичный вывод, а fallback гасит сам отказ разбора. Честная
дверь: total=-1 → `ОТКАЗ: ответ CI не разобран: total_count нет`, rc1,
журнал пуст. M11: writer проглатывает отказ и пишет check-строку (rc0);
