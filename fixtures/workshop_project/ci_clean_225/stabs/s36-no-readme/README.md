## Иной раздел

Политика очистки — `ops/server/ci-clean.json`; формат — `ops/server/ci-clean.schema.json`.
Сроки, корни, юниты, имена worker-процессов и lock_path берутся из конфигурации.

```sh
sudo bash ops/server/install.sh ci-clean
sudo bash ops/server/install.sh verify
sudo systemctl disable --now ci-runner-tmp-clean.timer
```

`ci-runner-tmp-clean.timer` имеет Persistent=true: простой станции не отменяет очистку.
`ci-artifacts-clean.timer` и существующий интерфейс артефактов 196 сохраняются.
Файлы конфигурации устанавливаются побайтно рядом с ci-clean.py; verify сверяет sha256.
CI_CLEAN_CONFIG и CI_CLEAN_SCHEMA задают явные пути файлов; пустой путь — отказ.
CI_ARTIFACTS_ROOT, CI_ARTIFACTS_RETENTION_DAYS и CI_ARTIFACTS_REPOS переопределяют конфиг артефактов.
Срок положительный целый; CONFIG_INVALID возвращает 1 до удаления и systemctl.

Для каждого active-раннера: freeze → frozen 1 → все cgroup.procs, включая дочерние cgroup → worker comm.
При BUSY сохраняется всё дерево этого раннера независимо от возраста, затем thaw.
При простое active-раннер заморожен до завершения удаления; inactive/failed можно чистить.
Неизвестный статус, нечитаемый proc/cgroup или отказ freeze — именованный отказ без удаления в этом корне.
Thaw выполняется в finally на успехе, отказе и SIGTERM/SIGINT; THAW_FAILED требует оператора.
Lock из конфига запрещает одновременные чистки; CLEAN_BUSY — отказ без замораживания.
SIGKILL/сбой питания не позволяют исполнить finally: оператор проверяет systemctl thaw для объявленных юнитов.
Не запускать параллельно стороннюю очистку/изменение cgroup или рестарт раннера вручную.

Возраст — по всему дереву без следования по симлинкам; молодой вложенный файл сохраняет запись.
Удаляются старые записи верхнего уровня, включая обычные файлы и имена с пробелами/переводом строки.
Симлинк верхнего уровня отклоняется TMP_SYMLINK; вложенный симлинк не ведёт к удалению цели.
Корни абсолютные, канонические, непересекающиеся, существующие, без симлинков во всех компонентах.
NUL недопустим в POSIX-имени и конфигурации; argv/потоки имён не разбираются по пробелу или переводу строки.

Живая установка — только оператор: Python3 с jsonschema и cgroup v2/systemd freeze необходимы.
Перед done оператор проверяет на станции долгий живой job и idle-раннер, freeze/thaw и verify.
Батарея без root доказывает CLI/деревья/проводку, но не подменяет эту живую проверку systemd.
