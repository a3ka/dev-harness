## Дельта

1. Б-1 → клетка empty-mark. До запуска литералы previous и точный отказ
make_task critic (rc 1, «ОТКАЗ: свидетельство не той роли: critic») фиксируются
в памяти. После запуска требуются тот же архив, пустая метка и тот же отказ.
Честный сосед existing-archive без файла метки остаётся зелёным.
Модель исправляет только условие сохранения архива: ! -e seed → ! -s seed.
EMPTY-MARK обращает его обратно (якорь кратности 1) и красит empty-mark.
Production этой пачкой не ремонтируется.

2. Б-2 → клетка archive-mode. На заполненном засеве проверяются полные байты
архива и метки и mode 0600 каждого файла. ARCHIVE-MODE меняет только
chmod 600 "$HARNESS_MODEL_TRACE.new" на chmod 644 (якорь кратности 1),
красит archive-mode, тогда как содержимое и mode метки остаются честными.

3. Б-3 → клетка partial-role. JSONL роли implementer-g (не ключ реестра,
префикс implementer-glm) соседствует со всеми разрешёнными строками.
Требуются точные SEED в обоих файлах и самостоятельная строка диагностики
TRACE_SEED_ROLE_UNKNOWN: implementer-g в полном stderr.
PARTIAL-ROLE меняет grep -Fx на grep -F (якорь кратности 1), красит partial-role.
Соседняя rejestr с outsider и честный список разрешённых ролей остаются зелёными.

Все три привязки — исполняемые mutations(model) + stabs.tsv.
Команда доказательства для каждого блока — W --stabs, rc 0:
честный контроль собственной клетки зелёный, адресный мутант красный.
Это новые наблюдения существующих И1/И2/И4/И5, без нового обязательства.
