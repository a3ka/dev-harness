# Канонические вставки 199 (модель-эталон)

Единый источник канонических блоков для `roles/orchestrator.md`
§«Изолированный спавн» (контракт 199): implementer переносит блоки в роль
ДОСЛОВНО, вместе с маркерами начала/конца. Батарея
`fixtures/workshop_project/sol_v_izolyacii_199/red_sol_v_izolyacii_199.sh`
извлекает блоки по маркерам и ИСПОЛНЯЕТ их (потребитель — приёмка; правило
единого источника: команда живёт в одном месте, роль несёт её байты).

Переменные обоих блоков задаёт вызывающий контекст роли (задание/сдача):
`WORKTREE`, `BRANCH` — носитель и ветка предмета; `SOURCE` — копия работника;
`AUTHOR` — роль; `ACCEPT` — путь `scripts/accept_task_commit.sh`; `ROOT` —
корень основного репозитория.

## Вставка ребёнку (продолжение ветки в своей копии)

Изолированный работник продолжает/создаёт авторскую ветку в СВОЕЙ копии
перед работой; `WORKTREE`/`BRANCH` — из задания (адрес доставки, источник
авторского tip — носитель):

```bash
# 199-baza-nachalo
git fetch --no-tags "$WORKTREE" "refs/heads/$BRANCH"
git switch -C "$BRANCH" FETCH_HEAD
git rev-parse HEAD
# 199-baza-konec
```

Расхождение полученного tip с ожидаемым — СТОП и доклад, не работа.

## Вставка ведущей (приём из копии: чистота → accept → синхронизация носителя)

Одним блоком: носитель доказанно чист ДО приёма (после приёма носитель
закономерно несёт расхождение индекса — замерено); приём — accept_task_commit
из копии; принятый tip фиксируется и носитель синхронизируется. Грязный до
приёма носитель не лечится — стоп.

```bash
# 199-nositel-nachalo
[ -z "$(git -C "$WORKTREE" status --porcelain)" ] || { printf 'ОТКАЗ: носитель грязный до приёма — не лечить\n' >&2; exit 1; }
TIP="$(bash "$ACCEPT" --source "$SOURCE" --branch "$BRANCH" --author "$AUTHOR" --root "$ROOT" | sed -n 's/.*tip=\([0-9a-f]\{40\}\).*/\1/p')"
[ -n "$TIP" ] || { printf 'ОТКАЗ: приём не дал tip\n' >&2; exit 1; }
git -C "$WORKTREE" restore --source="$TIP" --staged --worktree -- .
# 199-nositel-konec
```

После блока: следующий дозвон по предмету строится от ПРИНЯТОГО tip
(cherry-pick меняет sha — прежняя копия/источник не база), судьи получают
accepted tip, не старый source SHA.
