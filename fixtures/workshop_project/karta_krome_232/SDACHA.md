# СДАЧА 232 — грамматика пояснений ссылок, конфликт полной живой приёмки

Обещание: две основы самостоятельной ссылки, два новых вида пояснения; прежнее раскрытие того же класса и прямой статус сохраняются. Наблюдение — полный stdout/stderr/rc настоящего check_verdict_karta и раскрытая карта karta_proverit в реальных Git-мирах. Ожидания литеральны и находятся в памяти до запуска; модель не служит оракулом.

СТАТУС: бесконфликтная часть выполнена; ПОЛНАЯ МОДЕЛЬ КРАСНА, не готово к платному критику/заморозке. Причина — обязательный неизменённый live178.md:64 с прямым статусом «чисто в измеренных границах», вне frozen 193 И7. В `--model` и `--repo` клетка live178-as-is остаётся обязательной и ожидает rc 0; её не нормализовали и не превратили в отрицательную. `--reachable` и контроль `--stabs` явно сообщают ограничение области, не заменяют полный режим.

## Конструкция

Источник — production на 568f0ea63271e3461b574105cba8faec7563a8fd; build.py меняет только две альтернативы regex и выпускает полные носители библиотеки. 69 клеток; 10 мутаций; 33 адресные связи. Источник связей — build.py, source.json/stabs.tsv производные. Сверка TSV — побайтная с manifest, хеши всех носителей и живого файла проверяются до запуска. Каждая связь исполняется отдельно; честный контроль 68 бесконфликтных клеток обязателен первым. Синтаксическая ошибка/rc вне 0/1 не засчитывается поимкой.

Три формы живого хвоста проверены по отдельности для явной и относительной основы. У каждого запрета есть честный сосед: uppercase/произвольное соединение против lowercase, пустой текст против x, отсутствие точки против x., двойной пробел разделителя против одного; длинный текст имеет внутренние пробелы. Старые формы с точкой, без хвоста и с тире без точки сохраняются. Прямое пояснение с ссылочной лексикой не наследует блок исторического источника. Источники и SUBJECT — реальные Git-блобы; API обязан вернуть ровно ожидаемые К-01…К-17 и правильный К-05.

## Наблюдение процесса

Кандидат для main-журнала без самовольного А-номера: живой пример должен быть прочитан целиком до обещания зелёной модели. В 232 измеренная боль перечисляла три хвоста, но исходный артефакт дополнительно несёт неканоничный прямой статус К-15. После честного расширения ссылок отказ перемещается туда; нормализация образца или расширение прямого алфавита молча подменили бы предмет. Цена — блок полной модели; источник — live178.md:64 и реальный --model, класс — несовместимость обязательств задания с frozen-языком. ОТКРЫТО: полномочное решение о языке/объёме, ловец — оркестратор до критика. NABLIUDENIA_ARCHITECT.md не меняется в wip; запись в main делает ведущая сессия.
