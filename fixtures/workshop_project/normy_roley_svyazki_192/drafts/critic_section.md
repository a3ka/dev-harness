## Связка с автором (контракт 192)

Причина измерена (2026-11-11, 16 предметов, 50 вызовов): из 27 блоков повторных вызовов 23 открыты дельтой
исправления, 3 — узким закрытием, 1 пропущен ранее. Поэтому список классов общий с автором, повтор судит
дельта-лист, остаток получает имя и ловца.

Норма-строка (ПРОВОДКА roles/critic.md, заморожена 192/1):

На полном вызове вердикт несёт раздел `## Карта классов` — по строке на каждый класс К-01…К-17 из списка ниже: `К-NN: чисто — <команда и rc либо вход>`, `К-NN: блок — <заголовок блока>` или `К-NN: н/п — <причина>`; чисто без команды или входа не пишется; сначала перезапусти сдаточный лист автора (`bash scripts/check_sdacha.sh <корень> <контракт> --run`), расхождение его rc с заявленным — блок К-01 без разбора по существу.

Норма-строка (ПРОВОДКА roles/critic.md, заморожена 192/1):

На повторном вызове суди дельта-лист автора: закрыт ли класс шире примера (своя соседняя мутация), двусторонен ли каждый объявленный новый предикат (мутация красная, честная эквивалентная запись зелёная); семантическое изменение вне дельта-листа — блок К-01 `необъявленная дельта` без глубокой атаки; каждому блоку припиши строки `ПРОИСХОЖДЕНИЕ: дельта|узкое-закрытие|пропущен-ранее` и `КЛАСС: К-NN`; карта классов — те же 17 строк, незатронутые — `без изменений с вызова N`.

Норма-строка (ПРОВОДКА roles/critic.md, заморожена 192/1):

Блок, закрытый автором способом `граница` (остаток назван по свойству в `НЕ ЗАЩИЩАЕТ`, ловец назван и существует, обязательство предмета не сужено), считается закрытым; спор о допустимости границы — арбитру одним вопросом, не новый круг; каждая твоя мутация из вердикта после исправления обязана стать адресным стабом батареи автора — проверь это прогоном `--stabs`.

Список классов (единый источник; `roles/architect.md` ссылается сюда; новый класс — только из измеренного блока):
