## Оси

* **Профили:** 390×844, 393×852 (`PROFILI`). Каждая карта несёт оба.
* **Состояния:** из карты экрана (`sostojanija`: `id` + `vhod` — цель-вход).
  ref-clean: `start`, `profil`, `menu`, `menu_vorgang`; mob-ref: `start`,
  `profil`.
* **Обязательные цели:** из карты (`tceli[].objazatelna`), существование и
  включённость судятся на ХОЗЯИНЕ (И-1а).
* **Способы задания зоны ≥44 (Z):** z01…z12 — `zond/sinteticheskij-ekran.tsx`;
  все двенадцать зелёные (ложных отказов нет).
* **Способы сокрытия (V):** opacity 0 узла/предка, `display:'none'`,
  прозрачный фон+надпись, нулевой бокс, за экраном, за клипом, перекрыта.
* **Способы невидимой надписи (P):** скрытый Text, прозрачные буквы, вложенный
  прозрачный Text, нулевая ширина.
* **Треки:** `ЛЁГКИЙ` (по умолчанию) / `ПОЛНЫЙ`; строка
  `ТРЕК-ПЕРЕКЛЮЧЕНИЕ: ГГГГ-ММ-ДД (автор) ЛЁГКИЙ→ПОЛНЫЙ — причина`
  (грамматика эталона: цель стрелки ≠ текущего значения — стрелка объявляет
  переход ОТ текущего значения).
* **Шапка контракта:** класс риска объявляется строкой `КЛАСС РИСКА: <класс>`
  либо КОМПАКТНО — одной строкой с классом задачи («КЛАСС ЗАДАЧИ: КОДОВЫЙ.
  КЛАСС РИСКА: рисковый (деньги).»). Эталон читает оба объявления (упоминание
  маркера в прозе объявлением не является); клетки a01–a05 гоняют обе формы:
  риск-экран без трека отвергается в обеих, обычный экран и явный трек
  остаются зелёными.

## Режимы и коды возврата

| Режим | Что судится | rc |
|---|---|---|
| без флага | дерево харнеса: A, B, C, D, E, G + живая F именованной краснотой `LIVE_PREDPOSYLKA` | 0 — все клетки зелёные; 1 — красные; 2 — нечем проверить |
| `--model` | эталоны: клетки с внешним субъектом (живые референсы, гейт 159) не строятся | 0 |
| `--stabs` | контроль модели зелёный + каждый стаб отклонён на своих входах; `SVJAZI N` | 0; `STAB_ZHIV` — 1 |
| `--repo R` | гейт 159 первым, затем живая семья F на R | 0/1/2 |
| `--repo R --ekran N` | совместный режим: гейт 159, членство/ТРЕК, слой пачки, зонд R по карте пачки | 0/1/2 |
| `--ekran N` | экранный режим: контракт и пачка — по ОБЪЯВЛЕННОМУ маршруту (`NABOR_158_TOY_ROOT` либо корень дерева); неизвестный экран — rc 2, а не зелень | 0/1/2 |
