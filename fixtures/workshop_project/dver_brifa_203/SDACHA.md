## Обещание, наблюдение и совместимость

Обещание: exact pin исполняется с зависимостями совпадающего lock;
полный compact stdout вложен в допустимый пак либо дан именованный отказ
без частичного stdout. При ошибке CLI первая причина видна на первой строке
ARCH_BRIEF_OTKAZ. Наблюдение: настоящий make_task на автономных Git/Node мирах;
полное сравнение секции брифа, rc, первая строка stderr, отсутствие успешного
манифеста на отказе, счёт вызовов brief и сохранность донора.

Существующее: функции world/put/git из architecture_process_187/probe.py,
настоящие scripts/make_task.sh и check_architecture_contract.sh, прежний
pack_body. Модель — overlay в отдельной копии scripts, не таблица ожидаемых
ответов; её запускает тот же наблюдатель, что production. Ожидания полных
текстов, вызовов и отказов immutable в памяти до запуска. Стабы меняют
исполняемый код модели; адресные привязки только в stabs.py.

Исходные две двери модели читаются из точной БАЗЫ через git show, поэтому
реализация implementer не уничтожает якоря эталона. CI имеет fetch-depth: 0;
отсутствие объекта базы — rc2 среды, не молчаливое использование HEAD.

Frozen 170 запрещает замену брифа ссылкой; 187 требует pin и роли; 188 требует
схемы/invariants/writers/isolationKeys. Поэтому 203 не вводит срез: все данные
полного stdout сохранены, большой компонент получает ARCH_BRIEF_BUDGET с
рекомендацией. 91445 байт внутри 40000 не обещаны. Модель dependencies без
lock не заимствует; dependency-free мир 187 без lock сохраняется.

Демаркация — прежняя грамматика CLI/ID/профиля/pin; имена каталогов и Git SHA
генерируются мирами, оракул не привязан к ним. Успешные role-rules проверяются
для каждой из прежних ролей; два компонента и отказ второго — отдельно.
