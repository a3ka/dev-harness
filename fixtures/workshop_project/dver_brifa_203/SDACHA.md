ветке — доставка адресатом WORKTREE остаётся за оркестратором (наблюдение
ниже). Первый model-прогон выявил две ошибки сборки миров: fail-конфиг на
id из строки перехватывался гейтом членства раньше флага (причина-клетка
переведена на собственный код модели), freeze-мир без fail-конфига не
отказывал (добавлен UNKNOWN_FAIL). Один стаб (deps-donor-lock-optional)
оказался неисключимым на своём входе: предикат [ ! -f донорского lock ] —
мёртвая ветвь (cmp -s уже отказывает на отсутствии файла); мёртвая ветвь
удалена из эталона, стаб снят, честная проверка не ослаблена. Никаких
А-номеров вне зоны не резервировалось.

отказывает architect-коммитам на ветках wip/<NNN>/architect-<суффикс> при
живой wip/<NNN>/architect — суффиксированные ветки v2+ требуют либо
переименования ветки под <роль>-хвост, либо приёма коммитов в изолированной
