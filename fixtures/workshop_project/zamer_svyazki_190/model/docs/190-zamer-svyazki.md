# 190 — замер связки (Л6, С16): документ замера

Одна команда печатает таблицу мер связки architect ↔ критик по реестру предметов:

```
bash scripts/zamer_svyazki.sh --repo <корень> --zhurnaly <корень-сессий> [--s ISO] [--do ISO] [--predmety ERE]
```

- `--repo` — дерево харнесса (`verdicts/critic/`, `HANDOFF.md`, `registry/contracts.tsv`);
- `--zhurnaly` — корень сессий (`…/agent/sessions`); отсутствует → rc 2 `НЕТ_ЖУРНАЛОВ`;
  каталог есть, а записей в окне нет → rc 1 `ПУСТАЯ_ВЫБОРКА` (пустая выборка — красное);
- `--s`/`--do` — окно по началу сессии (имя каталога `YYYY-MM-DDTHH-MM-SS-…Z`);
- `--predmety` — фильтр номеров предметов реестра.

Коды возврата: 0 — таблица (stderr несёт `просмотрено: записей_журналов=<N>`, N>0 —
число просмотренного; пустая выборка не молчит); 1 — `ПУСТАЯ_ВЫБОРКА`; 2 —
`НЕТ_ЖУРНАЛОВ`/`НЕТ_РЕЕСТРА`.

## Канон таблицы (единый источник; печатается первой строкой вывода)

```
предмет	вызовы	fail	accept	обрывы	исход	блоки	первичные	дельта	узкое	пропущено	повтор	происх_не_уст	классы	классы_не_уст	arch_токены	arch_вызовы	crit_токены	crit_вызовы	одиночные_доля	хвост_доля
```

Строки — предметы реестра с судейскими вызовами или привязанными агентами; сортировка
по номеру. Строка `ИТОГО` и строка `МЕР` (среднее вызовов по установленным, доля accept
не позже второго вызова, предметы с 4+ вызовами) замыкают таблицу.

## Меры и их семантика

| мера | семантика |
|---|---|
| вызовы критика | уникальные (предмет, серия, номер) из учётных `СУД:`-строк: вердикт даёт ПЕРВУЮ `СУД:`-строку вне ```-цитат (цитируемые чужие СУД-строки вызовов не создают), HANDOFF — все `СУД:`-строки вне цитат; номер — ведущий цифровой кластер поля `вызов` (живые формы: `N/M`, `N/M (пояснение)`, `N`, `N (пояснение)`); слово-форма без цифр — предмет `не-установлен`, а не потеря; обрыв без вердикта — вызов; дубль-материализация — один |
| вердикт без `СУД:` | предмет помечается `не-установлен` во всех судейских столбцах, а не ноль; неузнаваемая слово-форма поля `вызов=` — тот же исход |
| исход | вердикт вызова с максимальным номером основной серии; `обрыв`, если вызов без вердикта |
| блоки | абзацы `БЛОКИРУЕТ` FAIL-вердиктов; происхождение `ПРОИСХОЖДЕНИЕ:` (первичный/дельта/узкое-закрытие/пропущен-ранее/повтор), класс `КЛАСС: К-NN`; нет строки → `не_уст`, не ноль |
| arch/crit токены и вызовы | по журналам сессий: `totalTokens` и число assistant-записей с `usage`; привязка — префикс имени файла агента (Architect/Arch, Critic/Crit), предмет — первый трёхзначный кластер в имени |
| одиночные_доля | доля вызовов модели с ровно одним `toolCall` (по architect-агентам) |
| хвост_доля | доля токенов после ПОСЛЕДНЕЙ правки (`edit`/`write`); агент без правок — весь его расход |

Роли вне замкнутого алфавита префиксов (reviewer, implementer, adversary, arbiter,
прочие) в столбцы architect/critic не попадают. Вывод не несёт путей и секретов
журналов — наружная поверхность замкнута столбцами канона.
