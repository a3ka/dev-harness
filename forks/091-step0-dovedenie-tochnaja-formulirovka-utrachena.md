ВОПРОС: HANDOFF.md (раздел «ГДЕ МЫ» на входе в эту сессию) указывал искать
точную дословную строку владельца «ПЕРЕВОД ПЛАНА» для шага 0 пути Г
(правка `ROADMAP.md §11` + `registry/plan.tsv`: 090→Контракт1 в составе,

сжатие-контекста→условные) через `history://` ТЕКУЩЕЙ (на тот момент)
сессии. После автоперезапуска (`orch_restart.sh`) эта сессия закрыта;
`read history://` в новой сессии показывает ТОЛЬКО текущую (`Main`,
running) — прежняя нерегистрированная top-level сессия НЕ персистентна
(правило инструмента: «bare lists registered agents, not persisted
unregistered top-level sessions»). Дословная строка владельца физически
недостижима инструментами этой сессии.

Смысловое содержание решения ДОСТУПНО (не как дословная строка, а как
пересказ) двумя путями:
1. `HANDOFF.md` сам называет точное содержание маппинга (090→Контракт1,
   091→Контракт2, 086→Контракт3, условные 079/076/паки/077/сжатие-
   контекста, id «цикл-перезапуска»→085 уже сделано).
2. `docs/owner/2026-10-08-roadmap-dovedenie.md` (коммит владельца
   `8a1b36c`/`01d413b`, идентичное содержимое) несёт ТУ ЖЕ таблицу
   сопоставления дословно (раздел «Сопоставление с текущими контрактами»).

Проблема НЕ в содержании (оно известно из двух независимых источников),
а в том, что правило 11 устава требует: строку `РАЗРЕШИЛ-ВЛАДЕЛЕЦ:
ROADMAP.md <причина>` пишет ТОЛЬКО владелец либо сессия по его ПРЯМОМУ
СЛОВУ, записанному в сессии; агенту писать её самому запрещено. Пересказ
из HANDOFF/docs/owner — не то же самое, что «прямое слово, записанное
строкой» для ЭТОЙ конкретной правки ROADMAP.md §11 (новый текст таблицы
ещё не существует дословно нигде, только человекочитаемое сопоставление).

Альтернативы (на выбор владельца):
(а) владелец даёт НОВОЕ прямое слово (новую дословную строку) для шага 0
    прямо сейчас — сессия берёт её как есть и выполняет правку с этой
    строкой как `РАЗРЕШИЛ-ВЛАДЕЛЕЦ:`;
(б) владелец подтверждает, что точный текст таблицы в
    `docs/owner/2026-10-08-roadmap-dovedenie.md` §«Сопоставление» САМ ПО
    СЕБЕ является достаточным «прямым словом» для вывода конкретной правки
    `ROADMAP.md §11` (т.к. это его собственный коммит, не пересказ) —
    тогда сессия формулирует `РАЗРЕШИЛ-ВЛАДЕЛЕЦ:` строку со ссылкой на этот
    коммит/файл как причину и действует;
(в) отложить шаг 0 до следующего прямого диалога с владельцем (очередь
    остаётся заблокированной только на пункте 4 плана — Контракт 1/2 после
    шага 0; остальная работа сессии идёт независимо).
