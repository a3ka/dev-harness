# 003 — модель сессии читается из ТРЕЙСА, а не из конфига

дата: 2026-08-16
вопрос: чему верить — конфигу или трейсу, при расхождении
решение: модель сессии читается из ТРЕЙСА, а не из конфига; орган проверки —
  `models:actual`
основание: cd7f1c9
область: запуск живой сессии и любая команда, читающая модель сессии
условие пересмотра: исчезновение трейса как источника истины для модели сессии,
  либо появление у omp источника, который трейс замещает без расхождений
