# 006 — у критика ПОРОГ: блокирует только находка с названным ОБХОДОМ

дата: 2026-08-17
вопрос: когда находка критика блокирует, а когда нет
решение: у критика ПОРОГ — блокирует только находка с названным ОБХОДОМ
  (конкретное состояние дерева, при котором объявленный критерий выполнен,
  а предмет не сделан)
основание: fa4457a
область: текст роли `critic` в `roles/critic.md` — раздел о пороге и метках
  находок; любой круг критика по любому контракту/плану
условие пересмотра: ослабление порога — только словом владельца, записанным
  в коммите правки роли критика, по процедуре устава
