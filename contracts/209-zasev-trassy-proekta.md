# Контракт 209 — засев архива трассы моделей нового проекта из трассы станции (бутстрап `HARNESS_MODEL_TRACE`)

СТАТУС: ЧЕРНОВИК-ЗАТРАВКА (bootstrap: `make_task --role architect` требует существующий `contracts/209-*.md`; текст контракта пишет architect по заданию станции — затравка не является ни спекой, ни критерием; заменяется целиком).

## Боль
Измерено 22.11 на новом проекте Complior-agent: `make_task --role architect --contract 137` → «ОТКАЗ: свидетельство не той роли: architect». Причина по коду (разбор станции `inbox-STANCIJA-TRACE-BOOT-0100.txt`): `workshop` `prepare_model_trace` (:237–258) строит архив `HARNESS_MODEL_TRACE` из `scripts/models_actual.sh --tsv` над зоной `$HARNESS_SESSION_HOME` проекта — по JSONL ФАКТИЧЕСКИХ сессий ролей в этом доме; у нового проекта запусков нет → пустой архив (`TRACE_ARCHIVE_NOT_READY`) → замкнутый круг: роль без запуска не получает строки, а запуск роли требует строки. Штатного пути засева нет. Обход 22.11: консультант вручную скопировал трассу back в дом агента (подтверждено владельцем задним числом как РАЗОВОЕ) — это не механизм, следующий проект повторит.

## Решение
Слово владельца 22.11: «новая задача станции — штатный засев трассы нового проекта из трассы станции». Направление (рекомендация станции, вариант Б): при пустой зоне проекта засев архива строками трассы станции (те же роли/модели по реестру `config/agent_models.json`), явно помеченными как засев (не как факт запуска в проекте); после первых реальных запусков ролей в проекте архив проекта — собственный. Нужное свойство и форму пометки формулирует architect.

КЛАСС ЗАДАЧИ: кодовый. КЛАСС РИСКА: обычный (трасса — свидетельство назначения модели, не права; ловец подмены — сверка `models_actual --bind` после первого запуска роли; при иной оценке architect/критик поднимает класс).
РАБОТА НЕ РАЗДАЁТСЯ: затравка; зоны и раздачу объявляет architect.

## Незаполненные требования:
- точные зоны (`workshop` `prepare_model_trace`, `scripts/models_actual.sh`, `scripts/make_task.sh` — что из этого трогается) и ПЕРЕСЕЧЕНИЕ с активными предметами;
- инварианты: засев только при пустом архиве проекта; засеянная строка отличима от фактической; собственная строка проекта вытесняет засеянную; засев не выдаёт роль, которой нет в реестре станции;
- красные клетки (пустой проект → роли проходят make_task; засеянная строка не выдаётся за факт; реальный запуск вытесняет засев; роль вне реестра → отказ) и стабы к ветвям — привязывает architect по коду.
