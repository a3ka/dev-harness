# Контракт 227 — Ш-5ф: шаг CI «зашивки проектов в ядре» в режиме отчёта (первый шаг потока Ш-5 по ключам профиля)

СТАТУС: ЧЕРНОВИК-ЗАТРАВКА (bootstrap: `make_task --role architect` требует существующий `contracts/227-*.md`; текст контракта пишет architect по заданию станции — затравка не является ни спекой, ни критерием; заменяется целиком).

## Боль
Слово владельца R-0114 (25.11, дословно): «План Fable добиваем: станция берёт новыми номерами по мере освобождения слотов, тремя потоками — (1) Ш-5 по ключам + Ш-5ф сразу в режиме отчёта, (2) Ш-3 owner-overrides, (3) Г-1…Г-9 одним контрактом с judges.policy; затем Ш-7 до возврата объёма под предел и Ш-8 замер. Л10 и текущие задачи станции — первыми». Норма R-0102: «хардкодить ничего не надо, все надо выносить в конфиги». Замер консультанта на main `6565542c1`: зашивок проектов в ядре — **89 строк в 20 файлах**; `legkij` в `check_ci_gate` — 6; `40000` в `make_task` — 1; `cli.js` в scripts — 2 файла; `ekran_shablon.py` есть.

## Решение (рамка)
Кодовый контракт, поток (1) в два хода:
1. **Ш-5ф сразу отчётом:** шаг CI в `registry/ci-steps.tsv`, печатающий остаток зашивок: `git grep -n -I -E 'Complior-(back|mob)|a3ka/Complior|complior-(back|mob)|\.harness/' -- scripts .omp/extensions .githooks ':!scripts/proxy'` — печать остатка, **rc 0, не блокирует** (мораторий на новые двери-отказы: единственное исключение — страж Ш-5ф, и он в режиме отчёта). Грамматика шага CI (команда начинается `bash <путь>`) и вес/замер — по `registry/ci-steps.tsv`; обёртка/скрипт печати — решает architect.
2. **Ш-5 по ключам профиля, по одному ключу за круг, порядок владельца:** (226 = `hooks.archBrief` уже идёт отдельным номером) → `ci.requiredChecks` (убрать `legkij`-литералы в `check_ci_gate`) → `hooks.judgeSetup` → остаток `pack.maxBytes` (литерал 40000 в `make_task`) → вынос моб-UI (`ekran_shablon.py`) после done 218 моба → вызов кита архитектуры через профиль (`cli.js`). Образец ключа — Б-4 `pack.maxBytes`, М-0, 203, 226. Ключи профиля — в `harness.project.json`; без ключа поведение для проектов не меняется («неизвестность ≠ выключено» там, где дверь — страж).
Критерий потока: счётчик шага Ш-5ф монотонно падает от замера 89 строк/20 файлов; по каждому ключу — `git grep` соответствующего литерала вне комментариев → пусто и игрушечный проект с иным repoId/значением ключа ведёт себя по ключу.
