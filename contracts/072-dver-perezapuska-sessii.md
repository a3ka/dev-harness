   реализации (прецедент gc_agent_branches.sh:273-275).
3. **Маркер атомарен по порядку.** Ставится ПОСЛЕ всех зелёных проверок;
   при любом отказе маркер отсутствует (не создаётся). Уже стоящий
   (перезапуск отложен) маркер дверь не удаляет — не её состояние.
4. **Мусорный worktree** := запись `git worktree list --porcelain` НЕ

   GC своего ROOT, затем переснимает список). Прочие мусорные → именованный
   отказ с путём (удаление запрещено).
5. **Легальные не трогаются:** основной чекаут и worktree на
   `wip/<NNN>/<автор>` — предмет жизни существующего GC (016/026/030),

6. **Тест-шов.** `ORCH_RESTART_MARKER` переопределяет путь маркера

8. **Коды возврата** (шапка «Коды возврата:» — реализационная пачка):
