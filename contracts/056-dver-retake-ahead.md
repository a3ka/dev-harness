## Инварианты (механизм: дверь `--retake-ahead`, scripts/check_no_leak.sh)

Грамматика CLI наследована: ровно два аргумента (режим + АБСОЛОТНЫЙ корень);
диспетчер узнаёт пятый режим, usage-строка перечисляет все пять: «ОТКАЗ диспетчер:
использование: check_no_leak.sh
--snapshot|--check|--retake|--retake-bulk|--retake-ahead <абс-корень>».
Переснятие ahead-дельты ПРОИСХОДИТ ⟺ СЕМЬ шагов ВМЕСТЕ (порядок: снимок-цел →
porcelain → двойное чтение → дельта → .git/*-ловец → членство в диффе → снимка):

1. **Снимок существует и цел** — защиты-снимка 024 дословно (симлинки
   файла/каталога/промежуточного, регулярный файл, root-строка, mode 0444,
   verify-строка и сходимость sha) — те же имена ветвей отказа, что у `--retake`
   (031 §Механизм-2 п.1); НОВЫХ имён для наследуемых защит не заводится.
2. **Porcelain чист:** `git status --porcelain` пуст → иначе «ОТКАЗ: переснятие-ahead
   не доказано: porcelain не чист — дельта обязана быть закоммичена».
3. **Двойное чтение манифеста** (TOCTOU 024-Б4 дословно): расхождение двух чтений →
   «основной чекаут мутировал во время сверки…» (имя 024, без изменений).
4. **Дельта непуста** (семантика 024: новые строки манифеста против базлайна; пути —
   поле за табуляцией, `sort -u`) → иначе «ОТКАЗ: переснятие-ahead не доказано:
   дельта пуста — нечего переснимать».
5. **Ни одного `.git/*` в дельте:** на КАЖДЫЙ путь дельты (лексикографический
   порядок) литеральный предикат из границы-3; первый же матч → «ОТКАЗ:
   переснятие-ahead не доказано: .git/* в дельте отказа: <путь> — СТОП и доклад,
   снимок не снимать ни по какой санкции (Н-165 п.9, Н-166)».
6. **Каждый путь отказа ∈ дифф:** вывод `git diff --name-only origin/main..HEAD`
   снимается ОДНИМ вызовом в память ДО посоставочного сравнения (оракул в памяти
   проверяющего, правило 8); rc вызова ≠ 0 → «ОТКАЗ: переснятие-ahead не доказано:
   origin/main недоступен» (fail-closed). На КАЖДЫЙ путь дельты (лексикографический
   порядок, первый отказ останавливает дверь целиком — частичных переснятий нет):
   литеральное построчное членство `grep -Fxq` → иначе «ОТКАЗ: переснятие-ahead не
   доказано: путь <путь> вне диффа origin/main..HEAD».
7. **Успех:** базлайн переснимается ТЕМ ЖЕ форматом (root + sorted + verify, mode
   0444 — переиспользуется do_snapshot), stdout несёт стенограмму — СТРОКА НА КАЖДЫЙ
   путь: «базлайн переснят: ahead-дельта <путь>», ЗАТЕМ итоговая «базлайн переснят:
   ahead-дельта — путей <N>, вне диффа 0», где <N> — число путей дельты; rc 0.
   Последующий `--check` → rc 0 «основной чекаут чист».

Отказ — rc 1, ИМЕНОВАННОЙ причиной (список выше — единый источник, фразы побайтово),
СНИМОК НЕ ТРОНУТ: последующий `--check` обязан остаться красным на той же дельте
(«переснятие, прячущее недоказанную дельту, краснеет» — слово владельца 2026-09-19,
наследовано из 031/044 дословно). Все внешние утилиты — через пины шапки скрипта с
проверкой rc (фикс Б7б 044: пин КАЖДОЙ утилиты, которую зовёт НОВЫЙ код).

`--retake-ahead` НЕ меняет семантики `--snapshot`/`--check`/`--retake`/`--retake-bulk`
(режимы 024/031/044 дословно — регресс-барьер: обе существующие красные фикстуры
семьи обязаны оставаться зелёными БЕЗ правки их текста).

## Модель угроз

ЗАЩИЩАЕТ:
- ручной ошибающийся оракул (г): конъюнкция проверяется кодом, а не вниманием
  оркестратора (класс Н-164(б)/Н-165/Н-166);
- `.git/*` в дельте отказа: именованный отказ СНИМКА, не человека — класс звучит
  именем и ловцом ДО membership;
- незакоммиченная дельта (porcelain), пустая выборка (пустая дельта → отказ, не
  молчаливый успех), недоступный origin/main (fail-closed);
- прячущее переснятие: отказ не трогает снимок, `--check` остаётся красным;
- дельта, не объяснённая ahead-коммитами: путь вне diff — именованный отказ с именем
  пути (забытый переснимок после пуша ловится здесь же: diff пуст).

НЕ ЗАЩИЩАЕТ:
- подлинность авторства ahead-коммитов: (г) не судит ни зоны, ни авторов (граница-4);
  чужая рука, закоммитившая в основной чекаут, пройдёт дверь, если её коммиты
  объясняют дельту — остаток класса «коммит ОТ ИМЕНИ» (044 дословно), наследован
  cognitive-only; стражи зон/коммитов — свои предметы;
- разошедшаяся история при непустом покрывающем diff: дверь судит состояние и его
  объяснение локальными коммитами, не слияние (граница-2); синхронизация — цикл
  gitw 045;
- утечка, дошедшая до честного коммита: Демаркация 024 наследуется дословно —
  детектор судит состояние, не историю;
- исчезнувшие пути: дельта 024 — новые строки; deletions невидимы (наследовано от
  024, не предмет 056);
- сговор/подмена локального git или PATH (TCB-арбитражи 040 дословно).
