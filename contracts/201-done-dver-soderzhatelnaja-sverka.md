## Модель угроз

ЗАЩИЩАЕТ:
- accept-вердикт, предшествующий последней заморозке, не открывает done новой версии (классы 141/991/999/109);

- несколько заморозок: дверь судит по vmax, а не по первому/старейшему тегу; accept эры старшей заморозки при тегах `/1…/N` отказывается (991/999; мутация «старейшая» красит клетку `a-dve-zamorozki`);

- место реализации ЯВНОЕ (РЕШЕНИЕ 2 арбитража 1): объявленная `ПРОДУКТ: станция` требует локальный OBJECT (внешний — отказ «обязан быть SHA станции»); объявленный или записанный в mesto-legacy продукт требует внешний SHA и влитость через API всегда, свежий accept на локальный станционный OBJECT отказывается (класс 163 — проверка не отключается локальной разрешимостью); НЕУСТАНОВЛЕННОЕ место (нет объявления и применимой записи) — именованный отказ fail-closed независимо от локальной разрешимости OBJECT; запись от другого blob не действует;
