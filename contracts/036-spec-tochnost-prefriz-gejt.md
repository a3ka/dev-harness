## Инварианты

Грамматики — ЕДИНЫЙ источник этот контракт; реализация несёт фразы ПОБАЙТОВО
(фикстуры сверяют дословно). Маркеры ищутся по ВСЕМУ файлу контракта (канон 008).

1. **Проба-строка:** `- `<cmd>`` с опциональным суффиксом ` → красная: <фраза>`.
   Суффикс извлекается срезом после маркера ` → красная: ` до конца строки; <фраза>
   непуста. Извлечение команды из бэктиков — та же логика, что в 008 (интерпретатор
   bash/sh/… → путь = следующий токен; иначе первый токен).
2. **Замер-строка:** `замер: `<cmd>` = N`, где N = `^[0-9]+$`; <cmd> исполняется,
   последняя строка stdout обязана быть целым и равной N.
3. **СПАСЕНО-строка:** `СПАСЕНО: <путь> — <причина>` (живая грамматика 003-v3/031-v4);
   <путь> обязан принадлежать множеству выпадающих; <причина> непуста.
4. **В1-семантика:** для каждой пробы: файла нет → отказ; rc 0 → ПРОПУСК (зелёная проба
   на заморозке — не дефект: ре-фриз реализованного предмета видит зелёное; свежесть-
   краснота черновика остаётся авторскому гейту Н-38 — асимметрия названа); rc≠0 без
   суффикса → отказ; rc≠0 с суффиксом и без <фразы> в выводе (stdout+stderr, grep -Fq) →
   отказ. Прогон — с таймаутом 60 с на пробу (зависшая проба = красная по имени таймаута).
5. **В3-семантика:** предыдущие версии = живые локальные теги `frozen/contracts/<NNN>/<v>`
   этого номера; контент ЗОНА-строк читается из тега (`git show <tag>:<отн-путь>`);
   выпадение = путь в ЗОНА <роль> union-версий, отсутствующий во ВСЕХ ЗОНА <та же роль>
   черновика. Нет предыдущих версий → ветвь пуста (vacuous green). Чтение реестра
   заморозок не удалось → именованный отказ (freeze к этому моменту уже проверил реестр
   писателем — расхождение двух читателей называлось бы сразу).
6. **Именованные причины (дословно):**

   - «спек-гейт 036: проба красна не по предмету: вывод не несёт заявленной причины»

   - «спек-гейт 036: СПАСЕНО не по грамматике: <строка>»
