## Инварианты

Грамматики — ЕДИНЫЙ источник этот контракт; реализация несёт фразы ПОБАЙТОВО
(фикстуры сверяют дословно). Маркеры ищутся по ВСЕМУ файлу контракта (канон 008).

1. **Проба-строка:** `- `<cmd>`` с опциональным суффиксом ` → красная: <фраза>`.
   Суффикс извлекается срезом после маркера ` → красная: ` до конца строки; <фраза>
   непуста. Извлечение команды из бэктиков — та же логика, что в 008 (интерпретатор
   bash/sh/… → путь = следующий токен; иначе первый токен).
2. **Замер-строка:** `замер: `<cmd>` = N census <glob>`; N = `^[0-9]+$`; <glob> —
   одиночный токен без пробелов, путь-глоб относительно корня. Гейт:
   (а) <glob> входит в <cmd> литерально (grep -Fq) — иначе отказ «census-глоб не входит
   в команду»; замер-строки без `census`-части — отказ «нет census-глоба»;
   (б) <cmd> исполняется с таймаутом 60 с; rc≠0 → «не исполнен»; последняя строка
   stdout обязана быть целым M1;
   (в) M1 = N — иначе «заявлено <N>, команда даёт <M1>»;
   (г) гейт САМ раскрывает <glob> от корня СВОИМ кодом (массив bash; несовпадение —
   пустое множество, счёт 0) → M2; M2 = N — иначе «заявлено <N>, дерево даёт <M2>».
   Вторая мера — ДРУГАЯ (AGENTS правило 4): не конвейер автора, а раскрытие гейта.
3. **СПАСЕНО-строка:** `СПАСЕНО <автор>: <полные 40-символьные хеши через пробел> —
   <непустая причина>` — грамматика 003-v3 (решение арбитража), живой потребитель
   `scripts/check_zones.sh:188–235`. <автор> обязан быть объявлен ЗОНА-строкой
   черновика; каждый хеш — полный SHA существующего коммита в окне
   frozen/contracts/<NNN>/1..HEAD (у done-контрактов — до done-тега). Псевдо-грамматика
   `СПАСЕНО: <путь> — …` первой редакции этого контракта — именованный отказ (Б1).
4. **В1-семантика:** для каждой пробы: файла нет → отказ; rc 0 → ПРОПУСК (зелёная проба
   на заморозке — не дефект: ре-фриз реализованного предмета видит зелёное; свежесть-
   краснота черновика остаётся авторскому гейту Н-38 — асимметрия названа); rc≠0 без
   суффикса → отказ; rc≠0 с суффиксом и без <фразы> в выводе (stdout+stderr, grep -Fq) →
   отказ. Прогон — с таймаутом 60 с на пробу (зависшая проба = красная по имени таймаута).
5. **В3-семантика:** предыдущие версии = живые локальные теги `frozen/contracts/<NNN>/<v>`
   этого номера; контент ЗОНА-строк читается из тега (`git show <tag>:<отн-путь>`);
   выпадение = путь в ЗОНА <роль> union-версий, отсутствующий во ВСЕХ ЗОНА <та же роль>
   черновика. Для каждого выпавшего пути: КАЖДЫЙ коммит автора <роль> в окне контракта,
   тронувший этот путь (diff-tree), обязан быть назван в хешах некоторой СПАСЕНО-строки
   того же автора — непокрытый коммит = отказ «перенос зоны». СПАСЕНО-строка вне

   ни с одним выпадением → «не привязан к выпавшему пути». Нет предыдущих версий →
   ветвь пуста (vacuous green). Чтение реестра заморозок не удалось → именованный отказ

## Остаточный риск (назван прямо)

1. В1 верит заявленной фразе автора: автор может заявить ПриЧИНой окружения («ОТКАЗ
   диспетчер…») — гейт отличит причину от повода, но не повод от предмета; ловит
   критик по стенограмме (cognitive-only, риск записан).
2. Пробы исполняются на рабочем дереве: злая проба может мутировать его. Канон приёмки —
   команды только читают; мутировать собственный черновик автору пришлось бы против
   себя. Полная изоляция (одноразовый клон на каждую пробу) отклонена по цене.
3. СЕМАНТИКА census-глоба — cognitive-only граница (названа вместо обещания): гейт
   связывает число с фактическим файловым множеством глоба (своим пересчётом) и с
   командой (литеральной вставкой), но релевантность самого глоба предмету числа
   (глоб может считать не те сущности) судит критик по тексту замер-строки. Числа
   не-файлового рода (коммиты, строки, секунды) замер-грамматикой НЕ покрываются
   умышленно: единственный независимо пересчитываемый класс — файлы; прочие числа
   остаются прозой на совести автора и критика. Утверждение «закрыт 035-класс»
   распространяется ТОЛЬКО на file-census.
4. Межконтрактные коллизии зон (same-role пересечения путей разных контрактов) не
   судятся: 031 и 033 легитимно делят NABLIUDENIA_ARCHITECT.md — отказ краснил бы
   живое дерево. Внутри-контрактный перенос (измеренная боль) покрыт В3.
5. Своевременность СПАСЕНО: покрытие хешей проверено механически, но НЕОБХОДИМОСТЬ
   спасения (нужен ли перенос вообще) — вопрос критика, не гейта.
