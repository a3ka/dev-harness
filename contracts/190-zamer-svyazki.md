(разделитель — табуляция; в документе — теми же байтами). Инварианты мер:

1. **Вызов критика** = уникальный кортеж (предмет, серия, номер) из `СУД:`-строк двух источников: вердикты `verdicts/critic/contracts-*.md` и `HANDOFF.md`. Поля разбираются по `;`, `k=v`; предмет — поле `предмет`, номер — число до `/` поля `вызов`, серия — текст в скобках поля `фаза` (пусто — основная серия). Дубль-материализация одного вызова несколькими файлами считается один раз.
2. **Обрыв без вердикта считается вызовом**: `СУД:`-строка в HANDOFF без вердикта с тем же кортежем — вызов с исходом «обрыв».
3. **Вердикт без строки `СУД:`** (файл `contracts-NNN-*.md` без `СУД:`-строки) — предмет помечается `не-установлен` во ВСЕХ судейских столбцах (вызовы, fail, accept, обрывы, исход, блоки и производные), а не ноль: ноль утверждал бы «судов не было», тогда как вердикт-файл существует, но не привязан к вызову. Журнальные столбцы (токены/вызовы/доли) остаются числами — привязка агентов идёт по именам журналов, а не по вердиктам.
4. **Исход предмета** — вердикт вызова максимального номера основной серии («обрыв», если тот вызов без вердикта; «-», если вызовов основной серии нет).
5. **Блок** — абзац, начинающийся строкой `БЛОКИРУЕТ`, только в FAIL-вердиктах; происхождение — самостоятельная строка `ПРОИСХОЖДЕНИЕ: первичный | дельта | узкое-закрытие | пропущен-ранее | повтор` внутри абзаца; класс — строка `КЛАСС: К-NN`. Отсутствующая строка происхождения/класса считается `происх_не_уст`/`классы_не_уст`, а не ноль. Столбец `классы` — агрегат `К-NN:count` по возрастанию номера класса.
6. **Меры журналов**: файлы агентов `<корень>/*/*/*.jsonl` в окне (сравнение секунд старта имени каталога с `--s`/`--do`); роль — замкнутый алфавит префиксов имени файла (Architect/Arch → architect; Critic/Crit → critic; Rev/Impl/Adv/Arb → прочие роли, в столбцы не попадают; остальное не считается); предмет агента — первый цифровой кластер длины ≥3 (лидирующие нули сравниваются числом; нет кластера — «без предмета», участвует только в ИТОГО). Вызов модели — запись `message` с `role=assistant` и `usage`; токены — `usage.totalTokens`; одиночный вызов — ровно один `toolCall` в `content`; правка — `toolCall` с именем `edit`/`write`; хвост агента — сумма токенов сообщений после ПОСЛЕДНЕЙ правки (агент без правок — весь его расход); доли считаются по architect-агентам предмета, ИТОГО — по всем architect-агентам (включая «без предмета»).
7. **Строки таблицы** — предметы реестра, у которых есть судейские вызовы, `не-установлен` или привязанные агенты; сортировка по номеру. Строка `ИТОГО` агрегирует установленное; строка `МЕР` несёт `среднее_вызовов` (по установленным), `accept_do_vtorogo` (предметы с accept-вызовом основной серии номером ≤2), `chetyre_plus` (предметы с ≥4 вызовами).
8. Неконсистентная строка журнала (не JSON) пропускается без падения; количество просмотренных записей печатается в stderr — обход обязан печатать число просмотренного и отказывать на нуле.
