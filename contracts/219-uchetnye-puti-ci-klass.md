## Боль
Слово владельца 23.11 (~23:35 UTC): «Б-15: брать после 217 — пути паузы, места и строк реестра считаются учётными (ci_klass), не кодовыми; измеренная боль 23.11: 5 PR станции остановлены Д4 после owner-PR и REPLACE.»
Измерено 23.11: классификатор `scripts/ci_klass.sh` (контракт 087) сравнивает хеши кодового дерева по набору учётных путей — строки `uchet<TAB><значение>` в `registry/ci-steps.tsv:35–44` (сейчас: `verdicts/`, `docs/`, `forks/`, `.review/`, `HANDOFF.md`, `ROADMAP.md`, `NABLIUDENIA*`, `registry/contracts.tsv`, `registry/closed-without-done.tsv`, `registry/plan.tsv`). В список НЕ входят `registry/pauzy.tsv`, `registry/mesto-legacy.tsv` (и, по сверке architect, `registry/risk-legacy.tsv`, `registry/lessons-harness.tsv`, `registry/dostavki/`): owner-PR паузы (#1315 pauzy.tsv) и места реализации (#1311 mesto-legacy.tsv) меняют кодовый хеш main → дверь Д4 консультанта («нет тяжёлого прогона для кода результата слияния») останавливает ВСЕ открытые PR, снятые до такого PR: 23.11 пересобирались 205 ×3, 210 ×4, 147 ×2, 157 ×3, 206 ×2, 211 ×3, 212 ×2 (по ≈1–2 пересборки на каждый учётный влив); пять PR станции остановлены Д4 после owner-PR и REPLACE (REPLACE `contracts.tsv` уже учётный; мест/пауз — нет).
Цена: ≈15 пересборок носителей и ≈10 повторных CI-прогонов за сутки (часть — из этой причины; остальное — окно PR, предмет 218).

## Решение
Кодовый контракт (расширение учётного набора, без правки кода классификатора): добавить в `registry/ci-steps.tsv` строки `uchet` для путей, содержащих ТОЛЬКО учётные данные (строки реестров/пауз/мест, не исполняемые правила): `registry/pauzy.tsv`, `registry/mesto-legacy.tsv`, и — по сверке architect — `registry/risk-legacy.tsv`, `registry/lessons-harness.tsv`, `registry/dostavki/` (если не читаются двери кодом как исполняемая политика). Реши: (а) критерий «учётный»: путь не определяет поведение гейтов/дверей на PR, меняется owner-PR/механизмом (mint_line/REPLACE/done), читается человеком/реестровыми дверями; (б) защита от сужения: учётный путь НЕ должен нести исполняемую логику (скрипт/правило) — иначе кодовое изменение пройдёт без тяжёлого прогона («неизвестность ≠ чисто»); граница с дверями, читающими эти реестры (`done_contract.sh` mesto-legacy, `check_plan.sh`, `zamok_predmeta.sh` pauzy/risk-legacy) — их ПОДСТАНОВКА/подмена строк не должна обходить Д4; (в) `registry/ci-steps.tsv`, `scripts/ci_klass.sh`, `.github/workflows/ci.yml` — защищены классификатором (`PROTECT`) — правка набора `uchet` проходит тяжёлым прогоном (кодовое изменение), один раз; (г) совместимость с 087 (классификатор), 114 (веса lane), 195, 207, 210 (активный), 217/218 (затравки), решения консультанта Д2/Д4 (дверь влива).
