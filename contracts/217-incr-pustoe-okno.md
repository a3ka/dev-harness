# Контракт 217 — `scripts/check_charter.sh --incr` при ПУСТОМ окне выходит сразу, без полного прохода по уставным документам (клетка 083 И0 перестаёт упираться в таймаут 60 с)

СТАТУС: ЧЕРНОВИК-ЗАТРАВКА (bootstrap: `make_task --role architect` требует существующий `contracts/217-*.md`; текст контракта пишет architect по заданию станции — затравка не является ни спекой, ни критерием; заменяется целиком).

## Боль
Слово владельца 23.11 (~22:30 UTC): «083 и окно check_charter в PR: поднимаю приоритет — станция берёт «--incr при пустом окне без полного прохода» и «окно check_charter/contract-frozen в PR» следующими после текущих предметов; таймаут не поднимать»; консультант: 217 — ВЫСШИЙ приоритет после текущих («клетка И0 56 с из 60 — скоро покраснеют все PR»).
Измерено 23.11 (станция): клетка `И0/check_charter` батареи 083 (`fixtures/ci_gen_083/red_ci_a_083.sh:1496–1505`) гоняет `timeout 60 bash scripts/check_charter.sh --incr <кеш=HEAD>` и ждёт rc 0 + маркер `incr: check_charter судит … (0 коммитов)` + кеш==HEAD; при rc 124 печатает ЛОЖНЫЙ диагноз «--incr не распознан, чек ушёл в полный прогон (timeout 60)» (режим распознан; маркер печатается сразу). В CI клетка длится 56,4 с на ЗЕЛЁНОМ #1310 (22:31:36→22:32:32) и 60 с (timeout) на #1314 (206 r6, КРАСНЫЙ четыре прогона подряд, в т.ч. в тихом окне) — на грани у ВСЕХ PR. Локально 10–15 с на свободной станции. Причина по коду: режим `--incr` при пустом окне всё равно исполняет полный цикл по 188–189 уставным документам с `git log <frozen-tag>..HEAD` (диапазоны ≈3300–5700 коммитов у документов 080/082/091/093/097/098/125/129) — до выхода по маркеру.
Цена: #1296/#1314 (206) — 5 красных obshchij подряд; консультант и станция ≈3 ч диагностики 23.11 (диагноз `inbox-STANCIJA-DIAG-OKNO-2400.txt`); блокирует Adv206d→done 206 по зелёному CI; под нагрузкой красит любой PR.

## Решение
Кодовый контракт: пустое окно (`<кеш>..HEAD` без коммитов) — немедленный выход режима `--incr`: маркер `incr: check_charter судит <кеш>..<HEAD> (0 коммитов)`, rc 0, кеш=HEAD, БЕЗ перечисления документов и БЕЗ `git log` по тегам; непустое окно — как сейчас (судит ровно коммиты окна, счётчики и per-document since сохраняются). Реши: (а) что считается «окном» и «пустым» (кеш = ранее проверенный HEAD; кеш не предок HEAD / неизвестен → полный прогон либо именованный отказ — «неизвестность ≠ чисто»); (б) защита от молчаливого сужения (правило 7): подделка кеша (чужой HEAD, не-предок, пустая/битая строка), силой вне сравнения; (в) судьба клетки 083 И0 (`fixtures/ci_gen_083/`, зона 083 — трогать только по слову владельца; лучше — клетка судит маркер, а не таймаут, отдельным предметом) и связь с 113 (быстрый check_charter), 210 (`charter_frozen_publication`; активный, Impl210c правит `check_charter.sh` — СОВМЕСТИМОСТЬ/ПОРЯДОК: 217 стартует по `check_charter.sh` после влива реализации 210 либо в непересекающихся функциях).
