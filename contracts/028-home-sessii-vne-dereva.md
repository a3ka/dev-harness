## Порядок миграции (церемония владельца, mv — не удаление)

1. Остановить живые сессии чекаута (все omp профиля dev на нём), включая демона
   (broker.sock переезжает вместе с `.zones`).
2. ДО-манифест (инвариант 5а): `cd <корень>/.zones/dev && find . -type f -exec sha256sum {} + | LC_ALL=C sort > "${TMPDIR:-/tmp}/028-migr.do"`
   — rc 0; пустой манифест при непустой зоне — красное, стоп. Сортировка —
   ПОЛНАЯ строка (LC_ALL=C), как сравнивает comm: `sort -k2` расходится с
   comm на общих префиксах путей (совет к2 вердикта).
3. `mkdir -p "${XDG_STATE_HOME:-$HOME/.local/state}/dev-harness-sessions/<hash8-корня>/zones"`
   — создаётся РОДИТЕЛЬ назначения (совет 1 вердикта v1: `mv` в
   `.../<hash8>/zones/dev` без родителя откажет на свежем внешнем корне).
4. Назначение УЖЕ существует (`.../zones/dev`)? — СТОП, именованный отказ
   церемонии, решение владельца: mv поверх существующего каталога не
   выполняется, молчаливое слияние/перезапись запрещены (инвариант 5б).
5. `mv <корень>/.zones/dev "${XDG_STATE_HOME:-$HOME/.local/state}/dev-harness-sessions/<hash8>/zones/dev"`
   — только mv; трейсы/agent.db — улики; ничего не удаляется.
6. ПОСЛЕ-mv-манифест ДО первого запуска (инвариант 5в):
   `cd .../<hash8>/zones/dev && find . -type f -exec sha256sum {} + | LC_ALL=C sort > "${TMPDIR:-/tmp}/028-migr.p1"`
   затем `comm -23 "${TMPDIR:-/tmp}/028-migr.do" "${TMPDIR:-/tmp}/028-migr.p1" > "${TMPDIR:-/tmp}/028-migr.poteri" 2> "${TMPDIR:-/tmp}/028-migr.comm.err"`
   — обязаны быть rc 0, пустой `028-migr.comm.err` и пустой `028-migr.poteri`:
   mv не потерял и не изменил НИ ОДИН файл байт-точно; несортированность = 
   красное церемонии, не сигнал (совет к2).
7. Перезапуск `./workshop`; контроля живой сессии: `omp config path` → внешний
   путь; `bash scripts/models_actual.sh` → находит трейсы, rc 0; каждый путь
   ДО-манифеста по-прежнему найден в новом корне (инвариант 5г — улики не
   стёрты первым запуском).
8. Непрерывность (инвариант 5д): `./workshop -r <id прежней сессии>` —
   продолжение поднимает прежнюю стенограмму из нового корня.
9. `bash fixtures/check_judge_gate/canary_solo_028.sh <абс-корень>` → rc 0
   (живая приёмка предмета: соло-сессия больше не валит сверку).
10. Остаток: пустой/чужой `.zones` в дереве остаётся как есть; `.gitignore:44`
   держит переход (инвариант 9).
