## Решение (рамка)
Кодовый контракт: `scripts/lib_owner.sh` (единый читатель) + `registry/owner-overrides.tsv` (данные). **ВСЕ прежние sha/РАЗРЕШИЛ-исключения переносятся без изменения решений** (каждый прежний sha — строкой файла; ни одно решение двери не меняется — критерий: на каждом перенесённом sha дверь отвечает прежним rc/текстом отказа). **Б-6** (sha-исключения `check_zones.sh` — в файл данных вместо кода) входит в этот контракт. Четыре двери — перечень по живому коду (architect): сверка `git grep -n -E '[0-9a-f]{40}' -- scripts/check_*.sh` и строки `РАЗРЕШИЛ-ВЛАДЕЛЕЦ`/`ALLOW-` в дверях. Строка файла: ключ двери, sha (или предикат), основание (ссылка на слово владельца R-NNNN), срок/пометка; грамматика — architect. Неразобранная строка — отказ с названным местом (правило 7 устава).
Критерий: sha-литералов в 4 дверях 237 → 0 (кроме комментариев-ссылок); файлов с `РАЗРЕШИЛ-ВЛАДЕЛЕЦ` в кодах дверей — вне `lib_owner.sh`/данных → 0; на честном дереве двери ведут себя как раньше (регресс затронутых барьеров), на обманном (sha не в файле) — прежний отказ.
