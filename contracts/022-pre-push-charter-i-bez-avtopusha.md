**Ветвь A — `.githooks/pre-push`: scoped чартер-суд диапазона пуша.**
Сегодня (код): между рабочим деревом и origin нет НИ ОДНОГО механического судьи устава —
pre-commit судит staged, CI судит origin ПОСЛЕ пуша (необратимо); remote-side pre-receive
на plain GitHub недоступен (факт хостинга). Новый `.githooks/pre-push` (exec-паттерн
pre-commit, `core.hooksPath` уже коммичен установщиком package.json:37): git подаёт хуку
на stdin строки `<local_ref> <local_sha> <remote_ref> <remote_sha>` на каждый пушимый
ref; отказ хука валит ВЕСЬ пуш. Договор суда:

1. **Все remote**, не только origin: хук судит каждую строку stdin независимо от того,
   куда пушат (сегодня remote один — семантика «все» дешевле специального случая).
2. Аннотированные теги разыменовываются `^{commit}` до коммита ДО суда; пуш тега РАНЬШЕ
   его линии даёт непустой судимый диапазон и умирает на красном — origin больше не может
   стать «тегом без своей линии» (Н-78(3)).
3. **Диапазон**: валидный `remote_sha` → `$remote_sha..$local_sha` (пуш main судит ВСЁ
   новое на main, даже уже уехавшее бэкапом wip-ветки мимо хука; force-push судится тем же
   диапазоном — лечение проходит, красный force умирает, см. И-3); нулевой `remote_sha`
   (новый ref) → `$local_sha --not --remotes` — первая экспозиция линии, и ТОЛЬКО она:
   уже публичное на любом remote повторно не судится.
4. **Судимое множество и вердикт — наследование scoped-семантики check_charter, кольцо
   ОДНО**: `is_charter_path`, `charter_diff_paths`, `razreshil` — ТОЛЬКО импортом
   `CHARTER_LIB=1` из `scripts/check_charter.sh` (прецедент потребителя
   check_staged.sh:72-76); вторая реализация кольца запрещена (прецедент
   lib_zones/lib_registry). Сегодня импорт возвращает из `check_charter.sh` ДО
   определения `razreshil` — зональная правка перемещает определение функции выше точки
   возврата `CHARTER_LIB` (см. Зоны; семантика и грамматика `razreshil` НЕИЗМЕННЫ —
   первая колонка, путь, непустая причина). Файл уставной с ПЕРВОЙ заморозки
   (`frozen/<dir>/<NNN>/1`, `ustav/1`) — коммиты ДО since вне суда; merge — по дельте к
   ПЕРВОМУ родителю (`charter_diff_paths`), веточные — по своей дельте; добавление
   уставного файла свободно (`--diff-filter=MD`).
5. Красный (устав-дельта M/D без РАЗРЕШИЛ в ТОМ ЖЕ коммите) → пуш умирает целиком,
   rc≠0, именованная причина — ПОЛНЫЙ диагноз: ref (полный, `refs/heads/…` либо
   `refs/tags/…`), коммит (полный sha; для тега — разыменованного), путь. Тройка
   равномерна в КАЖДОЙ честной красной фазе каждой hook-red фикстуры и в фазе 2
   push-пробы (арбитраж b43d7a0: точка отказа реализации может ветвиться по классу
   коммита/ref, обоснованного отказа от равномерности нет).
