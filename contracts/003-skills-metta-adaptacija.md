# Контракт 003 — скилы Мэтта: четыре адаптации и встройка в воркфлоу

Номер выдан механизмом: `next_id.sh CONTRACT` → 003, тег `id/CONTRACT/003`. План —
`plans/008-skills-metta-adaptacija.md` (все решения гриллинга Q1–Q16 зафиксированы в его
коммитах и сессии; живой прогон гриллинга — три раунда, ссылка на план как доказательство).

## Предмет

Взять из `mattpocock/skills` (снимок, источник — коммит клона на момент разбора) ЧЕТЫРЕ скила и
встроить их в воркфлоу так, чтобы роли знали, КОГДА что открывать:

1. `grilling` (+ обёртка `grill-me`) — интервью владельца до общего понимания: дерево решений,
   раунды по фронтиру, вопрос с рекомендованным ответом, факты — саб-агентом, решения —
   владельца.
2. `writing-for-agents` — грамматика документов для агентов: указатели, две нагрузки,
   иерархия информации, leading words, запрет отрицаний, выбраковка no-op'ов.
3. `tdd` — red → green цикл: швы, вертикальные срезы, антипаттерны (tautological,
   horizontal slicing).
4. `diagnosing-bugs` — дисциплина «тугого красного контура»: 10 способов построения, затяжка,
   недетерминизм через частоту.

Отказы — с причинами — в плане 008 (29 остальных скилов: сильные эквиваленты уже наши).

## Критерий готовности

1. **Скилы лежат и обнаруживаются.** `skills/` содержит ровно четыре каталога; тела —
   английские оригиналы снимка, шапка-адаптация на русском с исходным коммитом (провенанс).
   `bash scripts/check_skills.sh` → 0 — НОВЫЙ барьер, четыре ветви отказа: скил не обнаружен
   omp (захват запуска с подставным omp); имя каталога ≠ имени фронтматтера; адаптация без
   источника; каталог вне состава контракта. Каждая ветвь — красная фикстура.
2. **Указатели в ролях — гибрид.** Русское условие + английский leading word (совпадающий со
   словарём тела) + путь, по 1–2 строки: `roles/architect.md` — grilling (перед контрактом,
   когда предмет больше экрана или слово владельца), writing-for-agents (при правке ролей и
   нормы), tdd-ветка нетавтологичности (при письме красных фикстур объявленных ветвей),
   diagnosing-bugs (при построении проб и замеров); `roles/implementer.md` — tdd green-цикл,
   diagnosing-bugs (локализация в зоне). `grep -c 'skills/' roles/architect.md` ≥ 3,
   `roles/implementer.md` ≥ 2.
3. **Красные фикстуры объявленных ветвей пишет архитектор ДО раздачи** (решение Q8-C):
   фикстуры `check_skills.sh` по четырём ветвям лежат в коммитах архитектора до старта
   исполнителя. Ветви, найденные при реализации, добавляет исполнитель с пометкой — критик
   видит их в круге.
4. **Overlay кладёт, барьер проверяет** (Q14): `npm run overlay` раскладывает `skills/` в
   профиль omp и печатает ok-строку; `check:skills` в приёмке и CI (Q11 порог).
