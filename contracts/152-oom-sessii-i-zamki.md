## Frontier (решения по измеренной цене)

- **Механизм сторожа.** (а) крюк расширения на bash-вызов, судящий ТЕКСТ команды — ОТКЛОНЁНО: открытый язык shell, обходы `bash -c`/`env`/`sh`/абсолютный путь/симлинк/тень функции порождают новые (урок 148, девять форм). (б) **ДВОЙНИКИ В PATH ВНУТРИ SCOPE + журнал — ВЫБРАНО**: перехват на РЕАЛЬНОМ пути запуска — разрешении имени exec'ом через PATH; ловит голое имя, `bash -c`, `env`, `sh -c`, абсолютный путь К ДВОЙНИКУ, симлинк НА ДВОЙНИКА, вызовы из запущенных агентом скриптов и резолв компиляторов сборочными инструментами; доказательство — исполнение в песочнице, суд по журналу двойников. (в) cgroup DevicePolicy/seccomp — ОТКЛОНЁНО: отличает эмуляторы (/dev/kvm), но не нативные сборки (чистое вычисление), и требует root-перепроектирования запуска — не этот предмет.
- **Факт scope.** Kernel-факт `/proc/self/cgroup` содержит `orch-session-<pid>-<n>.scope` (потомок сменить свой cgroup не может) + env-маркер `ORCH_SESSION_SCOPE=1`, выставляемый orch-loop (второй канал: без станции CI-песочница судит маркером; снятие env агентом kernel-факт не отменяет).
- **Факт смерти holder.** (а) TTL-тишина — отклонена (воля: не через 60 мин; ветка Е 140). (б) состояние systemd-юнита holder'а — отклонено: отображение holder→юнит не существует. (в) **ЯКОРЬ `session_exit` В ЖУРНАЛЕ holder ИЛИ РОДИТЕЛЬСКОЙ сессии — ВЫБРАН**: байтовый литеральный `grep -F`, пишется omp при любом завершении (signal — убита, dispose — завершилась); покрывает OOM-sigterm, dispose-без-yield, рестарт станции (родительская сессия), 429-падения со записью; приоритет yield выше (сдавший не «погиб»). SIGKILL-мгновенная смерть без записи — честный остаток TTL (НЕ ЗАЩИЩАЕТ).
- **Снятие погибшего.** Авто-снятие под мьютексом предмета в `--sudit` (rm zanyat + RELEASE `prichina=pogib`) и немедленный `--osvobodit` (без TTL); на таймерную ветвь broshen НЕ распространяется (ветка Е 140 сохранена дословно — клетка c06).
- **Классы дополнения оркестратора.** (а) «ход без yield» (stop/429 С записью session_exit) — В ОБЪЁМЕ 152: тот же факт-якорь, та же ветка, измеренная боль Arch150f; 429-сессия ЖИВАЯ (ретраи окна, без записи) — не погибшая, вне 152 (слово владельца называет «погибших»; ловец сегодня — оркестратор `--osvobodit`; автополитика живых — отдельный предмет по слову). (б) «yield держит учёт до --osvobodit» — ВНЕ 152: воля называет погибших; изменение живого учёта групп — отдельный предмет (рекомендация в §Порядок).
- **OOM-факт orch-loop.** Литерал 085 пишется при `Result=oom-kill` юнита ИЛИ (старое) `scoped && rc=137`; systemctl недоступен/отказал — деградация к rc-правилу, без ложной маркировки и без остановки цикла.

## Предмет и инварианты

**Предмет (один наблюдаемый результат):** внутри scope сессии станции запуск эмулятора Android или нативной сборки ЛЮБОЙ формой разрешения имени отказывает именованной причиной со строкой журнала, безобидные команды проходят; вне scope эмулятор запускается только при <2 живых qemu на станции; замок предмета с доказуемо погибшим holder'ом снимается немедленно (авто в суде и `--osvobodit`), семантика 140 не ослабляется; orch-loop пишет литерал 085 по факту oom-kill юнита при любом rc.

- **И-1 (двойники).** Каталог `ops/server/user/dvojniki/`: ядро `_jadro.sh` + файлы-имена (замкнутый список 12: emulator, emulator-headless, qemu-system, qemu-system-x86_64, qemu-system-i386, qemu-system-x86_64-headless, gradle, cmake, clang, clang++, prebuild, expo). Ядро: имя запрета — первый аргумент от файла-имени (резолв `realpath`, симлинк считается именем цели); отказ в scope — rc 1 `ОТКАЗ: STROGO_SCOPE: …`; expo судит литеральные токены argv (`run:android`, `prebuild`), прочие свои запуски (export) пропускает к настоящему.
- **И-2 (факт scope).** В scope = `/proc/self/cgroup` содержит `orch-session-…-….scope` (kernel-факт) ИЛИ `ORCH_SESSION_SCOPE=1`. Вне scope имена нативных сборок — pass-through к первому настоящему бинарнику в PATH вне каталога двойников (нет — rc 127 `STROGO_NASTOJASHCHIJ_NET`).
- **И-3 (журнал).** Каждый отказ дописывает строку `${XDG_STATE_HOME:-$HOME/.local/state}/dev-harness/strogo-stancii.tsv`: `UTC, kontekst(scope|stanca), imja, argv` (printf %q). Pass-through не журналируется.
- **И-4 (предел ≤2).** Вне scope имена семейства эмулятора считают живые `qemu-system` (`pgrep -f '[q]emu-system'` минус собственный pid): ≥2 → rc 1 `ОТКАЗ: STROGO_EMULJATORY_LIMIT: …` (Astra п.342); нет pgrep → rc 2 NOT_IMPLEMENTED (fail-closed). Сторож не убивает чужие процессы.
- **И-5 (факт гибели).** `stare_holder` возвращает новое состояние `pogib`: журнал holder содержит `"customType":"session_exit"` (grep -F) И не содержит yield; ЛИБО родительский журнал (`<каталог-над-журналом-holder>.jsonl`) содержит якорь. Порядок: yield → pogib(свой) → pogib(родитель) → broshen(TTL) → bezhit; net_fajla как было.
- **И-6 (авто-снятие).** В `--sudit` занятый погибшим holder'ом замок снимается под мьютексом предмета (rm zanyat + RELEASE `prichina=pogib` в uchet.jsonl), предмет свободен — обычные проверки дальше; гонка двух судов — ровно один START (мьютексы 140).
- **И-7 (немедленный --osvobodit).** `pogib` → снятие сразу, `prichina=pogib`, без TTL; `bezhit` → `ZAMOK_ZHIV` как было (живой замок не освобождается).
- **И-8 (нет-ослабление 140).** Ветки yield/bezhit/broshen/net_fajla, все причины 140, лимиты групп, D10 «судья после yield автора» — дословно; судья на погибшем без yield авторе — `AVTOR_ESHCHO_RABOTAET` (автор не сдал); батарея `odin_agent_140` на реализации остаётся зелёной (приёмка реализации).
- **И-9 (OOM-факт).** orch-loop после немаркерного возврата читает `systemctl --user show "$SESSION_UNIT" --property=Result --value`; `oom-kill` ИЛИ `scoped && rc=137` → `log "… OOM: omp убит потолком памяти (MemoryMax=…, rc=…, Result=…)"` (литерал 085 сохранён).
- **И-10 (деградация).** systemctl нет/отказал — пустой Result ≠ `oom-kill`, цикл продолжает прежнюю логику («упала без маркера»), без остановки и без ложного OOM.
- **И-11 (проводка scope).** orch-loop добавляет в `SCOPE` `--setenv="PATH=<dvojniki>:$PATH" --setenv=ORCH_SESSION_SCOPE=1` (PATH собран значением до вызова); хвост команды после `--` не меняется (форма 085: пара `"$AGENT_CMD" "$MSG"` последними аргументами); каталог не установлен — громкая строка в журнал цикла, сессия продолжает (установка — тем же коммитом реализации, drift ловит install.sh verify).
- **И-12 (канон байт-в-байт).** Реализация: `ops/server/user/dvojniki/*` (13 файлов), `scripts/zamok_predmeta.sh`, `ops/server/user/orch-loop` == пинам `source.json:.nositeli` батареи (модель — эталон той же семантики, маркеры [S1]–[S5], [P1]–[P5], блок факта OOM).

Гигиена 041: нового структурного разбора чужого текста нет — суждение двойников: литеральные равенства токенов argv (разделила ОС) и замкнутый список СВОИХ имён установки; якорь гибели — литеральный `grep -F` без разбора; события/учёт — грамматики 140 дословно. Профиль parsing_hygiene не требуется (несёт новую грамматику — её нет).

ЗАЩИЩАЕТ:
