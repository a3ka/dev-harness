## Демаркация

Конформные входы (грамматика батареи): события `{"tasks":[{agent,name,task}]}`/flat с полями из замкнутых алфавитов (агент — роли config + scout/task/sonic/arbiter/…; имя `[A-Za-z0-9._-]+`; строки SUBJECT/OBJECT/PIN по инварианту 2, допускается ЛЮБОЙ прочий текст задания вокруг них — ровно это и судится); журналы holder — построчные JSON записей рантайма omp (типы `custom`/`message`/`custom_message`/…; произвольные строковые поля — включая литералы маркера сдачи; структурные поля записи принадлежат рантайму), yield-литерал/без, mtime; git-миры кандидата — ДЕРЕВО OBJECT с `contracts/`-записями произвольного состава (blob-файлы, симлинки mode-120000, каталоги-записи `<NNN>-*.md`), tip меняется amend, рабочий каталог — грязный; занятия замка (holder/класс/object), учёт (START/RELEASE/SLOVO любых предметов и групп), репо реестра (контракты с/без строки риска, risk-legacy.tsv, pauzy.tsv, теги done).
