## Модель угроз (норма 041: по свойству)

- ЗАЩИЩАЕТ: номер контрактного артефакта проектной сессии резервируется в `.git`
  ПРОЕКТНОГО репо, а очередь харнесса (id/-теги, registry/contracts.tsv) не
  трогается — пилотная боль (д) закрыта механизмом, не дисциплиной; реестр
  заморозок проектных контрактов живёт в дереве проекта (е); черновики болей
  проектной сессии не попадают в общий машинный пул харнесса — вектор смешения
  очередей (ж) закрыт; относительное значение env даёт именованный отказ ДО
  письма (path-injection).
- НЕ ЗАЩИЩАЕТ: подмену env владельцем сессии (TCB-класс 040 — локальное
  окружение под контролем исполняющего); гонку двух независимых клонов одного
  проекта (граница «гоночный клон» next_id — без изменения, дубль ловит check_ids
  при слиянии); запись болей мимо draft-инструмента напрямую в файлы харнесса по
  абсолютному пути — cognitive-only остаток, ловец — ревьюер сессии + норма R1 в
  промпте (промпт — носитель, не гейт); потребление недефолтных workflowPaths
  (Граница-5); домен почты самокоммита реестра в проекте (Граница-6).
- Самоприменение: красная батарея (§Красные предъявления) зелёная ДО заморозки —
  прецизионный пре-фриз гейт 043 увидит её в семье `workshop_project`.

- дано: env=`relative/path`; когда: любой из трёх вызовов; тогда: rc 1, stderr

- дано: env не установлен; когда: `bash scripts/next_id.sh CONTRACT` из
  чекаута харнесса; тогда: тег в харнессе, как сегодня (dev-ветвь жива).

  самостоятельной строкой и строки R2/R3 с каноническими значениями.
- Негативные пары: каждый сценарий выше имеет красную пару в батарее (стаб или
  до-реализационный прогон), где артефакт уходит на сторону харнесса — клетка
  обязана это поймать (И-5).
