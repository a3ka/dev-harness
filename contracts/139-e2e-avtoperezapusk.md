Любая ветвь/конкатенация/тэлл песочницы внутри шага — чужая строка кода, красна по построению. Ось окружения (replay CHISTYJ+ACTIONS) — НЕ замыкание класса: она доказывает env-инвариантность самой модели и даёт поведенческий свидетель env-ветвей; ось вызовов (argv-алфавит шима ровно трёх форм + PATH только `{bash,sed,grep,tr,mktemp,rm}` + gh-шим) замыкает и инструменты шага.
