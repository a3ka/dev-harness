субагентов не работает по двум независимым дефектам `.omp/extensions/path-guard.ts`:

- **(а) грамматика extractPin** — пин-пара `WORKTREE=/BRANCH=` не парсится в заданиях

## Инварианты (кодовые)

1. **Позиция пары**: пин-пара распознаётся в любой строковой позиции текста задания —
   якорь `^` с флагом `/m` (начало каждой строки) И якорь `[:;,]` (однострочные формы);
   голая двухстрочная пара, пара после префикса харнесса и однострочная
   `pin:WORKTREE=<абс>:BRANCH=wip/<NNN>/<автор>` дают пин.
2. **Алфавит значения**: двоеточие изъято из класса значения (`[^\s,;:]+`) — разделитель
   однострочной формы не съедается значением; в легитимных значениях (Linux-абсолюты,
   ветки `wip/<NNN>/<автор>`) двоеточия нет — изъятие ничего не сужает.
3. **Грамматика не ослаблена**: ровно одна пара (две WORKTREE-записи → null),
   basename-соответствие и живой git-оракул 032 сохраняются дословно (клетки а3/а4/а5).
4. **actual спавна**: фабрика берёт фактический cwd спавна из события — сначала
   `call.actual` (как и до пачки), затем `args.cwd` самого tool-вызова (bash несёт cwd
   ввода); `envActual = process.cwd()` демона — только последний фолбэк.
5. **М1-ветвь 037 нетронута**: ни одно из пяти условий `isSelfContainedCwdEligible` не
   меняется; поведение пары б1 (actual=клон → pass, actual=демон-cwd → block) живо до и
   после пачки.
6. **025/032-семантика вне предметов не тронута**: null-allowlist, URI-ветви, вектор
   утечки, приоритеты пина event > env > assignment — без изменений (регресс 31/31).

## Остаточный риск (назван прямо)

задания — вне этой пачки (граница 032, арбитраж 0c98913 §2).
