**Правило К (квантор множественных осей).** Для каждой множественной оси класс отказа, именованный её инвариантом, предъявлен в ДВУХ позициях: одиночным элементом (позиция 1) и «честный первый + дефектный второй» (позиция ≥ 2); у каждой множественной оси есть положительный контроль с ≥ 2 честными элементами. Классы:
- членство (И-2): {числовая без done-тега, символьная без закрытия} × {1, 2} + контроль двух. На OBJECT нет: `wave_second_symbolic_open` (111 done, sim-a закрыта, sim-b открыта → «sim-b не начат»), `wave_two_symbolic_closed` (ok v1). Заморожено/«номер выдан» — подвиды класса «без done-тега», остаются в позиции 1 как есть.
