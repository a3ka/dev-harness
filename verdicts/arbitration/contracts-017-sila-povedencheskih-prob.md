## Рассуждение

**p0.i.** Дефект — не в трассире (рантайм-наблюдение спавна верно по построению и
уже закрыло словарный класс v1), а в КАНАЛЕ: проба наблюдает файл по пути-конвенции,
а живой прокси получает вход через argv, где действует своё правило выбора. Любое
расхождение канала наблюдения с каналом потребления — дыра ровно того класса, который
проба обещает закрывать. Наблюдать надо там, где читает прокси: в argv спавна.

Дублирование `--config` ловить КАК КЛАСС — да. Прецедент 016 (§(в), мета-раздел):
там, где существует дешёвый детерминированный ассерт, закрывающий класс целиком,
класс закрывается механически; стандарт-А (объявление границы) — только для классов
без такого ассерта. Здесь ассерт — одна проверка счёта: у честной ветви ровно один
`--config` (проверено: proxy_up передаёт один), значит «больше одного — красный»
не даёт ложных красных и закрывает дубликаты в любом числе и порядке. Требование
единственности робастнее воспроизведения прецедентности парсера («последний
побеждает»): смена правила в парсере тихо устарила бы копию правила в пробе, а
единственность не зависит от правила выбора вовсе.

**И-4.** Дефект — не в идее «порог от измеренной базы вместо замороженного
wall-числа» (урок 015/016 остаётся в силе: числа стен на разных машинах разные), а в
ПРОИСХОЖДЕНИИ базы: она исполняет судимый proxy_up, и знаменатель порога растёт
вместе с числителем. Мера времени, чей эталон предоставляет сам измеряемый, не
мера. База обязана мерить скорость СРЕДЫ (node, прокси, TCP) без кода судимой зоны:
node — среда, `scripts/proxy/metering_proxy.ts` — замороженная поверхность
(`РАБОТА НЕ РАЗДАЁТСЯ`), минимальный конфиг проба пишет сама. Замер 4 показал: такая
база на порядок величины совпадает с прежней (318 против 423 мс — без накладных
proxy_up), честное дерево остаётся зелёным с запасом ~2.8×, а оба воспроизведённых
контрпримера уходят в красное. Это не мок стека (прецедент frontier §1В о
плацебо-изации барьера не задет): реальный node, реальный прокси, реальный TCP-healthz.

Кандидатура «отдельная минимальная контрольная ветвь» отклонена: контрольная ветвь
бежала бы тем же судимым пламбингом — тот же класс самосогласования, плюс цена.

## Решение по p0.i (однозначно исполнимое)

Трассир снимает ВСЕ значения `--config` из argv спавна (счёт и содержимое каждого
файла на момент спавна). Вердикт пробы:

1. счёт `--config` ≠ 1 → поимённый красный: спавн с неоднозначным конфигом
   (назвать счёт);
2. поле `port` единственного конфига на споне ≠ 0 → красный (как сейчас);
3. существующие проверки сохраняются: событие `.actual_port` от слушателя
   существует; конфиг ветви переписан на фактический порт; пустой снимок
   (спавн мимо трассира) — красный.

Наблюдение идёт ОТ ARGV — тем же каналом, которым вход получает парсер прокси; путь
файла как условие снимка не используется.

**Испытание (решающий исход):**

- Контрпример судьи: в одноразовом клоне применить к `scripts/check_metering.sh`
  дифф `tmp/critic/017v2-repro` (предвыбор порта краткоживущим слушателем, второй
  `--config` в спавне proxy_up), пробы не трогать →
  `bash fixtures/verify_antiplacebo/probe_port0.sh` обязана дать поимённый FAIL
  по p0.i с причиной неоднозначного конфига и rc=1.
- Вариация класса: предвыбранный конфиг ПЕРВЫМ аргументом, port:0 — вторым → тот же
  красный (единственность не зависит от порядка).
- Зелёный контроль: честная реализация среза 2 (один `--config`, в нём port:0 на
  споне) → p0.i ok; на текущем HEAD p0.i остаётся красной по прежней причине
  (предвыбранный порт в единственном конфиге), НЕ по причине неоднозначности.

## Решение по И-4 (однозначно исполнимое)

В ИЗМЕРЯЕМОМ пути базы не исполняется ни одна функция из зоны implementer
(`scripts/check_metering.sh`, `scripts/verify_antiplacebo.sh`). Допустимо: node,
`scripts/proxy/metering_proxy.ts`, собственный минимальный конфиг пробы, собственное
ожидание `.actual_port` + healthz, собственное гашение. Медиана трёх поднятий, счёт N
из финальной строки, ФАКТОР и вид формулы — остаются на архитекторе при условии
исходов испытания; `--selftest` сохраняет доказательство красноты ловца.

**Испытание (решающий исход):**

- Контрпример судьи: `sleep 2` в `proxy_up` + `sleep 20` в `branch_и` (только зона
  implementer, пробы не трогать) →
  `bash fixtures/verify_antiplacebo/probe_vetvi_ne_zamedleny.sh` обязана вернуть
  rc=1 с называнием замера и порога. (Замер 4: порог ≈19с при полном ≈45с — исход
  обеспечен уже нынешней формулой на независимой базе.)
- Зелёный контроль: честное дерево → rc=0 (замер: 6839 < 19080 мс, запас ~2.8×).
- `--selftest`: обёртка со sleep за порог → красное ловца, как сейчас.

**Дельта контракта (v3, санкционирована этим решением):** строка И-4
«против СОБСТВЕННОЙ базы того же прогона (медиана трёх поднятий прокси тем же
пламбингом …)» пинует дефект прозой и обязана смениться формулировкой независимой
базы (буквы — архитектора). Прозу p0.i контракт не пинует (привязка по коду проб,
Н-39) — И-1 текст не трогать.

## Границы (что этот арбитраж НЕ решает)

1. Перезапись единственного port:0-конфига в окно между exec и чтением его прокси —
   детерминированного ассерта внутри пробы нет без правки прокси (не раздаётся);
   реализация строго сложнее честной и недетерминирована — стандарт-А
   (критерии арбитража `krasnye-proby-granica-primera`), объявить в шапке
   `probe_port0.sh`; ловца здесь не заводить.
2. Преднамеренная порча внутренностей пробы sourced-кодом источника (переопределение
   утилит измерения) — вне класса слабой реализации; ловец — зонный страж и ревью
   коммитов, не эта проба.
3. Спавн мимо трассира (абсолютный путь node) — уже красный (пустой снимок);
   не переоткрывается.
4. Замедления ниже порога (например, sleep 5 в одной ветви) — терпимы текстом
   контракта; порог с запасом — осознанная цена против флейка меры.
5. Искажение счёта N в финальной строке — предмет части «не потеряны» (счёт одной
   мерой до/после), не этого стража.
6. Проводка `--port0` в CI, дым Q2, бюджет тиков — как в контракте, не предмет спора.

## Счёт по сторонам

Вопрос 1 (p0.i) — критику по существу: снимок одного конфига по условленному пути
класс не доказывает. Вопрос 2 (И-4) — критику по существу: самосогласованная база не
мера. Архитектору — конструкция обеих проб (рантайм-трассир, страж от измеренной
базы): она сохраняется, предписаны минимальные дельты в его зоне, ни мока стека, ни

оба решающих — воспроизводимость обоих контрпримеров и выполнимость обоих испытаний.
