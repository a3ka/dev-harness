## Диагноз

Тупик ч.1 настоящий, и он теоретический, а не исполнительский: инвариант
«hub безусловно» — это ∀-утверждение по всем окружениям. Конечная поведенческая
проба, чьи профили ЧИТАЕМЫ в её тексте, всегда подгоняема — контрреализация
обязана лишь распознать перечисленные классы. Статический текстовый суд без
анализа потока данных обходится косвенной сборкой имени; полный dataflow-анализ
bash неразрешим. Ни расширение списка классов, ни расширение текстовых шаблонов
гонку не заканчивает — обе сети «перечислительные», это класс Н-89 (треадмилл).

Выход — сменить проверяемую форму: судить не «hub в предъявленных профилях», а
**env-НЕЗАВИСИМОСТЬ операнда, предъявленную тождеством между свежеслучайными
окружениями, класс которых не существует до запуска пробы**. Подгонка под
конечный список бессильна, когда списка нет: предикат контрреализации обязан
покрыть ~весь носитель опубликованного распределения выборки — а тогда он
эквивалентен честному «hub всегда» всюду, куда выборка достаёт.

Тупик ч.2 — НЕ настоящий. Гонка «следующая контрреализация пропустит art://»
опровергнута границами договора: `artifact://` обязан PASS (null-allowlist,
слово владельца 2026-09-11), а множество block-обязанных схем ЗАКРЫТО и поимённо
заморожено инвариантом 2.3 ({`local`, `skill`, `agent`, `history`, `mcp`} плюс
не-carve-out `xd://`). Дефект A-030-7 — рукописная таблица, недопокрывшая
конечное перечисление; это чинится порождением строк ИЗ перечисления, а не
бесконечным дописыванием.

## Решение по кандидатам

- **(а) манифест `./workshop --print-tools` + тождество выводов** — в манифестной
  форме ОТКЛОНЁН, в инвариантной ПРИНЯТ. Манифест — самоотчёт проверяемого о
  собственном инвентаре: вторая реализация рядом с exec-путём; его
  env-независимость ничего не доказывает об операнде exec — это тот же класс
  «суд самоназвания», который арбитраж транспорта (redizajn-transporta-030)
  уже отклонил для stdout. Вдобавок он требует правки workshop вне измеренной
  боли и v2 заморозки (форма наблюдения «состояние $TOOLS В ТОЧКЕ exec» пиннута).
  Его РАБОЧАЯ часть — «N случайных env → ТОЖДЕСТВО» — переносится на УЖЕ
  существующий канал наблюдения (Т-1..Т-5) без единого касания workshop:
  замеры 4/5 доказывают исполнимость (A-030-6 красен всеми проходами, честное
  дерево зелено).
- **(б) семантика под секретом** — ОТКЛОНЁН: в toy недоказуем, поверх nonce-канала
  ничего не добавляет.
- **(в) признать остаток cognitive-only при текущих сетях** — ОТКЛОНЁН в текущей
  редакции сетей (три фиксированных класса подогнаны исполненным A-030-6),
  ПРИНЯТ как второй шаг ПОСЛЕ смены формы: остаток существует, он назван ниже
  границей, и он на порядки уже сегодняшнего.
- **(г) пин/sha артефакта launcher** — ОТКЛОНЁН: пиннит форму реализации, которую
  контракт пиннить не обещал (арбитраж Б1: легальный v4-сорс обязан зеленеть);
  каждая будущая легитимная правка workshop краснила бы постоянную пробу.
- **(д)** — принятая композиция: (а)-инвариант на существующем канале + норма
  границы + порождённая таблица ч.2. Ниже как предписание.

## Предписание архитектору — круг 4 (финальный), обе правки в зоне fixtures/, без respec и без v2 заморозки

**Ч.1 — `red_inventar_hub.sh` (И-1..И-4):**

И-1 (случайный класс). Генерация окружения живого суда заменяется: N ≥ 6
проходов; значение каждого прохода — свежая криптослучайность запуска по
ОПУБЛИКОВАННОМУ в коде пробы широкому распределению (длина случайна в широком
диапазоне, алфавит собирается случайно из нескольких пулов, включая не-ASCII;
метринг-переменные — отдельные выборки). Классов в тексте пробы НЕ существует —
подгонка под «все предъявленные» лишается предмета подгонки.

И-2 (тождество). К инварианту «hub в операнде КАЖДОГО прохода f0 и proj; hub
ни в одном f1» добавляется инвариант тождества: операнды всех проходов попарно
ИДЕНТИЧНЫ в пределах режима (f0 к f0, f1 к f1, proj к proj). Любая
env-зависимость операнда — именованный rc 1, даже если hub уцелел.

И-3 (неизменность остального). Транспорт Т-1..Т-5, батарея деревьев, мини-workshop'ы,
статическая сеть (остаётся ВТОРОЙ дешёвой сетью — она красит `shape` и ленивые
текстовые контрреализации), дисциплина rc 0/1/2 и доминирование слома — не
пересматриваются. Дерево A-030-6 (замер 1) добавляется в батарею исполненным
классом с ожиданием red — привязка по коду (Н-39).

И-4 (v5). В awk-программу `mkvar v5` добавляется завершающее правило `{ print }`.
Проверено арбитром: v5 строится, судится красным rc 1 (проектный путь, инв. 1'),
честная проба целиком rc 0 (замер 7).

**Ч.2 — `red_kanal_qa_report_issue.sh` (И-5..И-7):**

И-5 (порождение из перечисления). Block-строки непинна ПОРОЖДАЮТСЯ
кросс-произведением: {`local://`, `skill://`, `agent://`, `history://`, `mcp://`}
× {write, edit, bash-операнд} — 15 порождённых block-строк, каждая судится в
ОБОИХ каналах (CLI и factory). Пропуск схемы становится невозможен ПО ПОСТРОЕНИЮ:
строки не пишутся руками, они выводятся из списка-литерала, зеркалящего
инвариант 2.3. Гард полноты (SUZDENO==ZAYAVLENO) сохраняется.

И-6 (случайность внутри схемы и вне перечисления). Хвост пути каждой порождённой
строки — случайный токен запуска (`skill://<случайное>` и т.д.): подгонка под
конкретное значение умирает. Плюс строки дефолт-запрета: случайная НЕИЗВЕСТНАЯ
схема (`<случайное>://x`) у непинна → block. Судится РЕШЕНИЕ, не причина: замер 6 —
честный страж блокирует `mcp://` и случайную схему ветвью относительного пути с
иной причиной; пин причины дал бы ложный красный на честном дереве.

И-7 (неизменность остального). Существующие 15 строк, единый конструктор events(),
регистрация factory, стаб-привязки S-* — без изменений; `artifact://` у непинна
остаётся pass-строкой (владельческий allowlist — не block-цель, «гонки art://» нет).

## Граница остаточного риска (норма; симметрична норме транспорта)

Обход моделирует сокрытие дефекта ПРЕДМЕТА, не подгонку под слепое пятно
измерителя. После И-1/И-2 основанием круга по ч.1 признаётся ТОЛЬКО
контрреализация, дающая ложный rc 0 на СВЕЖЕМ полном прогоне пробы с её
собственной свежей случайностью (судья гоняет пробу как есть — этого достаточно).
Cognitive-only остаются и основанием круга НЕ становятся:

1. предикаты, вырезающие множество пренебрежимой меры под опубликованным
   распределением выборки (магические значения; таргетирование точного формата
   боевого секрета): такой предикат кодирует знание слепого пятна выборки, то
   есть целит в инструмент, — аналог «чтения файлов инструмента ради nonce» из
   нормы транспортного арбитража; реальные инженерные дефекты условности
   (пустота, семейства форм, выбор провайдера) имеют непренебрежимую меру и
   красятся с подавляющей вероятностью;
2. условность по осям, которые проба не варьирует (время, hostname, состояние
   ФС вне HOME/зоны): проба доказывает env-независимость по варьируемым осям —
   секрет, метринг, HOME/зона; остальное — глаза критика, как и до 030.

По ч.2 остаточного риска в границах инварианта 2.3 не остаётся: перечисление
закрыто, порождение исключает пропуск, случайные хвосты и случайные схемы
исключают позначную подгонку.

## Приложение — набросок суда И-1/И-2 (доказательство исполнимости; код не предписан дословно, Н-39)

    #!/usr/bin/env bash
    # 6 случайных env случайного КЛАССА → тождество операндов + hub в каждом
    set -uo pipefail
    TREE="$1"; BASE=/tmp/dev-harness-verify/arb-030; N=6
    OPS="$BASE/sketch/ops.$$"; rm -f "$OPS"; fail=0
    for i in $(seq 1 $N); do
      V="$(python3 -c '
    import secrets, sys
    pools = ["abcdefghijklmnopqrstuvwxyz", "ABCDEFGHIJKLMNOPQRSTUVWXYZ",
             "0123456789", "абвгдежзийклмнопрстуфхцчшщыэюя", "-_.:+/="]
    n = 5 + secrets.randbelow(44)
    alpha = "".join(pools[secrets.randbelow(len(pools))] for _ in range(3))
    sys.stdout.write("".join(alpha[secrets.randbelow(len(alpha))] for _ in range(n)))
    ')"
      M="$(python3 -c 'import secrets; print(secrets.token_urlsafe(secrets.randbelow(30)+5))')"
      rm -f "$BASE/operand.txt"
      ( cd "$TREE" && PATH="$BASE/stub:$PATH" HOME=$BASE/fh HARNESS_SESSION_HOME=$BASE/zn \
        ZAI_API_KEY="$V" METERING_PROXY_URL=http://127.0.0.1:1 METERING_PROXY_TOKEN="$M" \
        MINIMAX_API_KEY="$M" ./workshop ) >/dev/null 2>&1
      [ -s "$BASE/operand.txt" ] || { echo "СЛОМ: проход $i — exec не наблюдён"; exit 2; }
      OP="$(cat "$BASE/operand.txt")"
      case ",$OP," in *,hub,*) ;; *) echo "ОТКАЗ (инв. 1): проход $i — hub отсутствует"; fail=1 ;; esac
      printf '%s\n' "$OP" >> "$OPS"
    done
    [ "$(sort -u "$OPS" | wc -l)" -eq 1 ] || { echo "ОТКАЗ (тождество): операнд зависит от окружения"; fail=1; }
    exit "$fail"
