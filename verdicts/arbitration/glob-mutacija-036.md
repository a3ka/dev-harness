## Корень А (граница корня) — прав адверсарий; дизайн (а) physical-resolve

Лексика ≠ разрешение — подтверждено прогоном (замер 1). Пересчёт, включающий объект
вне дерева-кандидата, не является «пересчётом файлов по глобу от корня» (frozen п.2(г))
— это дефект РЕАЛИЗАЦИИ замороженного обещания, а не дыра текста. Правка — код
(`scripts/check_spec_ready.sh`, зона implementer), ре-фриз не нужен.

Обязательные свойства фикса (замерены в п.3 выше):

- сверка КАНОНИЧЕСКАЯ с обеих сторон: `ROOT` уже `pwd -P`; каждый элемент раскрытия —
  `readlink -f`, отказ при `$rp` вне `$ROOT/*` и не равном `$ROOT`;
- применяется к ОБОИМ раскрытиям гейта — M2_pre И M2_post; отказ на M2_pre срабатывает
  ДО исполнения M1 (`bash -c "$cmd"` не запускается на уже-беглом глобе);
- именованный отказ, канон формата: «спек-гейт 036: census вне корня: <путь>
  разрешается вне дерева-кандидата»;
- лексические проверки (`/*`-префикс, сегмент `..`) ОСТАЮТСЯ как ранний дешёвый
  барьер — physical-resolve их не заменяет, а замыкает класс;
- стоимость: один `readlink -f` на элемент раскрытия — ограничена размером дерева,
  возражение цены снято;
- симметрично закрыть тот же класс, если раскрытие производится где-либо ещё
  (второго места в текущем коде нет — проверено чтением В2-ветви).

Внутрикорневые symlink'и легальны (замер 3.3): запрещается не переход по ссылке,
а физический выход разрешённого объекта за канонический корень.

## Корень Б (M1-restored-mutation) — прав автор; граница (б), закрывается толкованием

Довод адверсария «реализована проверка равенства двух чисел, не свойство „изменение
дерева → отказ“» опровергается замороженным текстом: свойство «изменение → отказ» НЕ
обещано (замер 4). Обещана согласованность заявленного N с двумя независимыми мерами.
В эксплоите Б census-утверждение «в дереве 1 файл *.txt» ИСТИННО на обеих границах
окна; ложной заявки нет — нечего ловить.

Решающий структурный довод: M2_pre — собственное раскрытие гейта, взятое ДО передачи
управления M1. Чтобы ЛОЖНАЯ заявка N прошла, нужно M2_pre = N, а M2_pre автору
недоступен — он снят с нетронутого дерева. Значит restored-мутация НЕ создаёт канала
для ложного census: любые махинации внутри окна M1 зажаты двумя гейт-контролируемыми
границами. Persist-мутация ловится (к2-матрица адверсария: `k2-m1-create-remove` →
«дерево даёт 0», `k2-m1-background` → «дерево изменено замер-командой» — обе красные,
остаются). Требование «наблюдать операцию, не два конечных числа» — это требование
изоляции/трассировки исполнения, т.е. ОС-механизм (прецедент d2ffb8e / yakor-git-032
«Страж не песочница», замер 4: закрытие враждебного кода требует
bubblewrap/namespaces/seccomp — вопрос воли владельца, не инженерный спор). Предмет
036 — гейт спек-точности, не сандбокс; frozen §Остаточный риск п.2 это уже
зафиксировал и изоляцию отклонил по цене.

Норма-толкование (обязательна к цитированию в вердиктах по 036 вместо повторного
спора): **census-гейт 036 гарантирует согласованность заявленного N с деревом на
границах окна проверки (M2_pre и M2_post — собственные раскрытия гейта) и с командой
(M1); неизменность дерева ВНУТРИ окна исполнения M1 не гарантируется и не судится;
персистентная мутация — именованный отказ; restored-мутация не образует ложной заявки
и дефектом не является.** Кандидат (в) (множество вместо числа) отклонён: конечные
множества эксплоита равны ({base} → {base}), различения не даёт, цена есть.
