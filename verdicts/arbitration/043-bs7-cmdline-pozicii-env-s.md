## Решение по существу

**Прав критик — по обоим вопросам предмета.**

**Вопрос 1: две позиции окончательного cmdline НЕ достаточны, и недостаточен КАК
КЛАСС любой фиксированный индекс.** Лемма фикс-коммента (`:440-441` — binfmt_script
несёт максимум один shebang-аргумент, путь «ВСЕГДА на 1 или 2, НИКОГДА дальше»)
верна для ОДНОГО ядерного преобразования и неверна для наблюдаемого объекта: гейт
читает cmdline ПОСЛЕ userspace-преобразований, а GNU `env -S` (документированная
штатная возможность coreutils, §env-invocation) заново разрезает один ядерный
аргумент на несколько — путь уезжает на argv[3], argv[5] и далее без предела
(З1). История кругов — Б5→Б6→Б7→env -S — это та же гонка аппроксимации за
вычислителем, что класс 1 арбитража 042: каждый круг закрывает предъявленную
топологию и получает следующую. Класс закрывается только снятием позиционного
допущения.

**РЕШЕНИЕ (механизм):** живость барьера в /proc-оракуле определяется literal-сканом
ВСЕХ NUL-полей `cmdline` процесса-потомка с индекса 1 (не только 1-2): любое поле,
ПОБАЙТОВО равное канонически-абсолютному пути барьера, — live. Сравнение — только
`[ = ]`/`case`-литерал, никаких regex/glob (норма 041 §Инварианты п.2(iii) — без
изменений). Измерено З2/З3: класс закрыт, 16/16 красной пачки не регрессируют.

Цена решения, названная прямо: скан всех полей РАСШИРЯЕТ поверхность совпадения
«путь барьера как данные чужого argv». Это НЕ новый класс риска: тот же ложный
accept измеренно присутствует в сегодняшних позициях 1-2 (З4, `tail -f` → rc 0)
и УЖЕ объявлен контрактом именованным остаточным риском (§Модель угроз
НЕ ЗАЩИЩАЕТ: «путь барьера оказывается данными аргумента постороннего вызова …
страховка — критик»). Расширение того же принятого остатка оплачивается правкой
формулировки НЕ ЗАЩИЩАЕТ (снять привязку к позициям, назвать «в любом поле argv»),
не новым механизмом.

**Отклонённые альтернативы, названные явно, чтобы к ним не возвращались:**
- очередной сдвиг предела (3→4→6 полей) — четвёртый точечный индекс, следующая
  форма `env -S` с большим числом опций гарантирует круг 6;
- разбор опционной грамматики интерпретатора («первый не-опционный аргумент») —
  новая аппроксимация: `-o pipefail` разносится на два поля, второе не начинается
  с `-`; `--`, `-c`, не-bash интерпретаторы — каждый следующий член класса свой
  круг. Ручная реконструкция грамматики чужого вычислителя — ровно то, что
  арбитраж 042 отверг доктринально.

**Вопрос 2: честный прямой вызов со штатным shebang — ЧАСТЬ обещанного предмета.**
Контракт обещает подтверждение того, что «барьер семьи подтверждённо исполнен
ЖИВЬЁМ» (:35-45, :62, :177-183) и нигде не ограничивает форму shebang барьеров
семей; `env -S` — документированный штатный механизм интерпретации shebang, не
враждебное окружение (исключение ENV TRUST :66-69 не применимо — окружение вызова
не подменялось, З1 это подтверждает). Молчаливое сужение «прямой вызов, но только
без env -S с двумя+ опциями» запрещено правилом 7 AGENTS.md («не молчаливое
сужение области»); красное с ложным диагнозом на честном входе — нарушение того
же правила. Гейт судит БУДУЩИЕ семьи произвольных авторов — форма shebang их
барьеров не в юрисдикции гейта.

## Что обязан предъявить круг 6

3. §Модель угроз НЕ ЗАЩИЩАЕТ: формулировка argv-данных остатка обновляется на

4. Круг 6 — обычный круг критика; предмет: соответствие этому вердикту +
   действительно новые дефекты. Решённое здесь не переоткрывается; FAIL по
   смещению пути в окончательном argv — дефект исполнения, чинится правкой,
   не спором.

## Именованный остаток вне предмета (не блокер этого арбитража)

Контроль З4 (`cat`-вариант, rc 1) измерил: /proc-оракул — СЭМПЛИРУЮЩИЙ, живость
требует временнОго перекрытия процесса барьера с опросом; фикстуры семьи держат
барьер живым `sleep 1`. Честный БЫСТРЫЙ барьер (< интервала опроса) может быть
пропущен тем же ложным «не вызван живьём». Это не предмет данного спора и не
судится здесь; автору — задокументировать как именованный остаток (или закрыть),
критику — обычная страховка следующего круга. Прецедентная дисциплина — «остатки
в §Риски дословно» (арбитраж 042, Граница п.4).
