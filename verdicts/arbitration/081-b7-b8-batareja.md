**Замер 1 (Б7) — потеря rc в обёртке `irun`.** Код :467-469:

```sh
irun(){ out="$(... bash "$INSTALL" root 2>&1)"; rc=$?; }
```

Последняя команда функции — присваивание `rc=$?`; его собственный статус 0, он и
становится статусом `irun`. Клетки I1/I1b (:473, :482) читают глобальный `$rc` —
корректно. Клетка I2 (:490) читает `irun "$SANDBOX/i2"; irc=$?` — получает 0 всегда;
далее :502 `[ "$irc" -eq 0 ] || i2ok=0` никогда не красит клетку по rc. Воспроизведено
прогоном идиомы вне батареи:

```text
$ bash -c 'f(){ out="$(exit 1)"; rc=$?; }; f; irc=$?; echo "rc=$rc irc=$irc"'
rc=1 irc=0
$ bash -c 'f(){ out="$(exit 1)"; rc=$?; return $rc; }; f; irc=$?; echo "rc=$rc irc=$irc"'
rc=1 irc=1
```

Трасса критика (`+ rc=1` / `+ irc=0`, итог 29/0) согласуется с этим ровно. Факт
критика подтверждён. Остальные условия I2 (атрибут стоит, запись отказывает ядром,
значение не записано, журнал: ровно одна `+i`, ни одной `-i`) в обходе Б7 подлинно
выполнены — обход ловится ТОЛЬКО условием rc, которое и сломано.

**Замер 2 (Б8) — «журнал пуст» подменён «нет строки `+i <config>`».** Контракт
:374-375 (I1): «chattr НЕ вызван (журнал пуст)»; :376-377 (I1b): «chattr НЕ вызван»;
И-2 :141: «в клетках I1/I1b батареи мок-chattr НЕ вызван (журнал вызовов пуст)». Мок
chattr (:194-197) пишет в журнал КАЖДЫЙ вызов:
`printf '%s\n' "$*" >> "$MOCK_STATE_DIR/chattr.log"` — строка `-i <путь>` в журнале
появляется. Условия клеток :474/:483:

```sh
&& ! grep -Fq "+i $SANDBOX/i1/.git/config" "$CHATTR_LOG"
```

запрещают только одну форму строки. Вызов `chattr -i <config>`, `chattr +i <другой
путь>`, `chattr -i` без аргументов — все оставляют условие истинным при непустом
журнале. Факт критика подтверждён чтением; его мутант (29/0, «chattr не вызван»
при вызванном `-i`) с этим кодом иначе завершиться не мог.
