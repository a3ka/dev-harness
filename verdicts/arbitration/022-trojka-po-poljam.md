# Арбитраж 022: тройка диагноза по полям — форма приёмочного входа push-пробы (круг 4)

Созыв: два FAIL по одной причине (вердикты `e91c99a` круг 3 и `ddababa` круг 4 —
оба о том, что red-вход И-10 не наблюдает суд КАЖДОГО поля тройки) плюс правило 15
(созыв без согласия автора). Предмет (формулировка критика круга 4): достаточно ли
ЕДИНСТВЕННОГО различающего входа, где вывод push-пробы не содержит НИ ОДНОГО из
трёх полей (полный ref, полный sha, путь), для требования п. 2 РЕШЕНИЯ `b43d7a0`
«фаза 2 судит КАЖДОЕ из трёх» — или нужны входы с по-одному-отсутствующим полем
либо иная форма тождества. Стороны: автор конструкции (architect, дельта
`aa67706` + `7fb23fb`) и критик. Класс — третий рецидив Н-75 «барьер судит
подмножество»: 018 F-4 — подмножество путей, 022 круг 3 — подмножество фаз,
022 круг 4 — подмножество полей. Кап 30 мин соблюдён; терминология нейтральная
(Н-73).

## Воспроизведённые факты

Все замеры — одноразовый клон `wip/022/architect` (`7fb23fb`) в
`/tmp/arb022polya.797g96/repo`; pwd-эхо печаталось перед каждым прогоном (А-95),
rc снимался отдельным оператором; основной чекаут не мутирован (Н-68/016).
Инструмент замера: `scripts/check_hooks.sh` клона заменён параметрической
исполняемой моделью push-пробы (двухфазный toy bare-origin по образцу стаба
фикстуры; судимое множество полей — параметр `CHECK_FIELDS` ⊆ {ref, sha, path};
rc пуша и неподвижность origin-ref судятся всегда), закоммичен в клоне
(`0309221`), чтобы `git archive HEAD` фикстуры его подхватил.

**Замер 1 — контрольный эксперимент: вход-2 «все 3 поля отсутствуют» убивает
только форму ∅.** `red_check_hooks_bez_push_faz.sh` прогнан против всех восьми
подмножеств:

| судимое множество S | rc фикстуры |
|---|---|
| {ref} — контрпример критика | 0 |
| {sha} | 0 |
| {path} | 0 |
| {ref,sha}, {ref,path}, {sha,path} | 0, 0, 0 |
| {ref,sha,path} — честная | 0 |
| ∅ (только rc + неподвижность) | 1 «push-фаза 2 не судит тройку» |

Контрпример критика круга 4 воспроизведён и обобщён: red-файл на tip `7fb23fb`
не отличает слабую реализацию, судящую ЛЮБОЕ непустое собственное подмножество
полей (шесть форм), от честной тройки. Причина механическая: в выводе входа-2
отсутствуют все три поля сразу, поэтому первый же ассерт ЛЮБОГО судимого поля
краснит пробу — вход наблюдает «судится хотя бы одно», а не «судится каждое».
Утверждение И-10 «закрытый конечный набор форм (нет фаз / фазы без тройки /
честные) покрыт двумя входами» (`contracts/022-…md:165-167`) опровергнуто:
классификация пропускает шесть форм «фазы с частичной тройкой».

**Замер 2 — диагональ входов «по-одному-полю-нет» (кандидат Н-75, форма
прецедента замера 4 арбитража `94f2c15`).** Построены хуки H_без_i: чистый
диапазон пропускают, красный отвергают причиной, несущей два других поля и
молчащей о поле i; плюс контрольные H_все_три и H_ничего. Матрица 5×8 (40
клеток, 6.5 с): проба формы S краснеет на входе H_без_i ⇔ i ∈ S — диагональ
точная, без единого исключения. Следствия, снятые с матрицы:

- пережить все три диагональных входа (красна на каждом) способна ТОЛЬКО полная
  тройка {ref,sha,path};
- каждый диагональный вход попутно убивает и ∅ (столбец ∅: rc 0 на каждом
  H_без_i), и форму «push-фаз нет вовсе» — текущий вход-2 различающей силы
  сверх диагонали не несёт;
- честный хук H_все_три зелёный под всеми формами проб — диагональные входы
  зелёный путь честной реализации не трогают (red→green достижим, А-96).

**Замер 3 — цена.** Red-файл сейчас 190 строк; генератор всех трёх диагональных

новых файлов и семей. Время: полный прогон фикстуры 0.6 с, клетка матрицы
0.16 с — добавка к прогону < 2 с.

**Замер 4 — закрытые пункты не ослабляются.** И-8 (tag-канарейка) и равномерная
тройка в семи hook-red закрыты кругом 3 срезом `e91c99a` и предметом спора не

## Решение по существу

**Спорный пункт — за критиком.** Единственный вход «все 3 поля отсутствуют»
недостаточен: он наблюдает дизъюнкцию («судится хотя бы одно поле»), тогда как
п. 2 РЕШЕНИЯ `b43d7a0` требует конъюнкцию («судится каждое»). Шесть слабых
реализаций проходят названный критерий (замер 1). Требование трёх отдельных
наблюдений — не максимализм критика, а минимальная форма, при которой конъюнкция
наблюдаема кодом.

**Обязательная к исполнению форма входов** (`red_check_hooks_bez_push_faz.sh`,
тот же red-файл, без новых файлов):

1. **Три диагональных входа** вместо нынешнего входа-2 как носителя различения:
   вход-ref (причина отказа несёт полный sha и путь, молчит о полном ref),
   вход-sha (ref и путь, без sha), вход-path (ref и sha, без пути). Каждый хук
   пропускает чистый диапазон; предмет-фаза требует на каждом корне rc≠0
   `check_hooks` с причиной про pre-push. Основание: замер 2 — только полная
   тройка переживает все три.
2. **Вход-1 (no-op)** остаётся как есть: форма «фаз нет вовсе» умирает своим
   именованным предъявлением, его стаб-ассерты не меняются.
3. **Вход «все 3 отсутствуют»** разрешено оставить как документирующий
   исходную слабую форму e91c99a либо убрать — по выбору автора; считать его
   несущим различение запрещено (замер 2: он строго слабее объединения
   диагонали).
4. **Стаб-привязка (Н-39):** параметрический стаб «судит всё, кроме поля i»
   гоняется диагонально — обязан быть ЗЕЛЁНЫМ на своём входе i (дефект
   наблюдаем именно там) и КРАСНЫМ минимум на одном чужом входе (стаб жив).
   Полная матрица 3×3 допустима (цена < 2 с), не обязательна.
5. **Текст И-10:** формула «закрытый конечный набор форм … покрыт двумя
   входами» удаляется как опровергнутая; заменить пер-полевой: «для каждого
   поля тройки существует вход, наблюдающий именно его отсутствие; пережить
   все входы может только проба, судящая каждое поле». «Красное сейчас»
   переписывается под фактический набор входов.

**Взвешенные альтернативы** (по обязанности созыва): (а) статус-кво —
опровергнут замером 1; (б) тождество полного текста причины с эталоном —
различает сильнее, но морозит формат диагноза, принадлежащий зоне implementer,
и ломается на любом легитимном изменении формата — отклонено; (в) три отдельных
red-файла — та же сила, цена ×3 по строкам и семьям конверсии — отклонено по
цене; (г) диагональ в одном файле — принято: минимальная достаточная форма,
+30–45 строк.

**По классу Н-75:** кандидат-решение «пер-элементный со-локализованный
свидетель» подтверждён замером на третьем рецидиве подряд (пути → фазы → поля).
Рабочая формула для будущих барьеров: требование «судит каждый элемент
множества» наблюдаемо только набором входов, где элементы отсутствуют
ПО ОДНОМУ; вход «отсутствует всё сразу» наблюдает лишь «судится хотя бы один».
