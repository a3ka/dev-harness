## Остаточный риск и ловцы

**Открытый К-10 не принимается остаточным риском.** Отнесение суффиксной подмены к НЕ ЗАЩИЩАЕТ либо ослабление конкретности диагностики — **К ВЛАДЕЛЬЦУ**. Рекомендация: обязательство сохранить, выполнить конечный ремонт выше.

Сохраняется прежняя граница ложной модели/обхода project CI; готовая строка, не новая санкция риска:

> НЕ ЗАЩИЩАЕТ: различение точного pin в диагностике не доказывает истинность содержимого закреплённой архитектурной модели и не исключает сознательный обход проектного CI; ловцы — reviewer реализации по источнику модели и публичной двери, предметный CI по поставленной батарее, adversary в предусмотренном рисковом реализационном суде. Подмена значения pin в обязательном отказе в этот остаток не входит.

Не назначать adversary обычному предмету только ради этой строки. Конечная батарея не является доказательством отсутствия любой мыслимой ошибки; новый доказанный зависимый регресс нельзя скрыть словом scope. Новая версия/имя файла/этот арбитраж не обнуляют ни один счётчик.
- **Арбитр санкции не выдаёт.** Предлагается единственный конечный узкий суд после ремонта; остаток численного лимита сам по себе не запускает следующий. После этого суда без accept автоматического продолжения нет: дальнейший вызов по данному конечному маршруту, полный круг, смена обязательства/риска — **К ВЛАДЕЛЬЦУ**. Рекомендация при необходимости отдельного бюджетного слова — разрешить ровно описанный узкий вызов на новом OBJECT, без ослабления обязательства.

Свежий critic-accept обязателен. Настоящий закоммиченный титул — артефакт арбитража для машинного капа, не accept и не обещание успешного freeze. Сохраняются штатные предсудебные двери, проверки зон/проводки и остальные машинные гейты; новых тегов этим решением не создаётся.
