## Решение по пунктам

**1. Ревьюер прав по фактам во всех спорных пунктах.** Замеры 1, 3, 4 воспроизводят к2
дословно. Утверждение имплементера в шапке `UNSCOPABLE_KEYS` («scoped-прогоны гоняют раннер
НА КАЖДОМ шарде … сам-тест покрыт косвенно на каждом пуше, отдельный шаг не нужен»)
измеренно ложно: исполнение раннера не есть исполнение его сам-тестов, и 23 case
`fixtures/verify_antiplacebo/` не гейтятся в CI ничем. `gen-harness` и `check_metering` в
споре не участвуют (закрыты в к2 и Н-103 соответственно).

**2. По действию — развилка 1 в scoped-форме: отдельный шаг сам-тестов на минимальном
корне.** Исполняет implementer 020 в своей зоне (`.github/workflows/ci.yml`,
`scripts/verify_ci_parity.sh`, `config/ci_parity_exceptions.txt`):

- шаг в джобе `ci` (вне matrix): собрать mktemp-корень из копии
  `scripts/verify_antiplacebo.sh` и `fixtures/verify_antiplacebo/`, исполнить
  `npm run check:antiplacebo -- "$TMP_ROOT"`. Имя скрипта статично и канонично (правило 6);
  аргумент ломает равенство значению → шаг ОПЛАЧИВАЕТСЯ одной записью
  `команда: … = <причина>` в `config/ci_parity_exceptions.txt` — ровно тот механизм оплаты,
  который назначил первый арбитраж; прямой вызов `bash scripts/verify_antiplacebo.sh …` в
  workflow НЕ писать (красный флаг residual);
- цена измерена: 52 с стены локально (замер 5) — минуты CI, не часы; `timeout-minutes`
  джобы не трогается;
- раннер НЕ правится (заморозка круга соблюдена), `scope_select.sh` НЕ правится (зона 006
  заморожена), слово владельца НЕ требуется: воля/деньги не затронуты (~1 мин CI), а
  замороженный инвариант 3 не ослабляется — он ВОССТАНАВЛИВАЕТСЯ: после шага вне CI-гейта
  остаются только 22 case `check_metering`, чьё изъятие уже записано словом владельца
  (Н-103). Изъятие `verify_antiplacebo` из инварианта исчезает.

**3. Ложная компенсация стирается.** Текст «покрытие обеспечено исполнителем каждого
шарда» в шапке `UNSCOPABLE_KEYS` (`verify_ci_parity.sh:1125-1132`) заменить фактическим:
покрытие — отдельным шагом сам-тестов на минимальном корне, оплаченным записью в
`ci_parity_exceptions.txt`; пункт «full-прогон отсутствует по дизайну (Н-48)» верен и
остаётся.

**4. Развилка 2 (residual по образцу Н-103) ОТКЛОНЕНА.** Residual требует слова владельца,
владелец спит; будить его не нужно, потому что механизированное закрытие существует и
стоит ~1 мин CI (замер 5). Записывать остаточным риском то, что закрывается пятьюдесятью
секундами исполнения, — ослабление без ценового выигрыша. Требование НЕ открывается.

**5. Развилка 3 (`scope_select` учит ключ сам-раннера) СЕЙЧАС НЕ ОТКРЫВАЕТСЯ.** Гарантия
была бы ТА ЖЕ, что у шага из п.2 (судья==подсудимый — та же граница замера 7), а цена —
расморозка зоны 006 и новый контрактный круг. Корневой дефект при этом НАЗВАН для очереди:
`header_role` в `scope_select.sh` не якорён и расходится с грамматикой `classify()` раннера
на одной и той же шапке (замер 2); адрес фикса — `^`-якорь по образцу `classify()`; класс —
«две грамматики одной шапки», может бить и по другим файлам с примерами маркеров в
документации. Решение об открытии — владельца/архитектора в обычном порядке; условием
закрытия 020 НЕ является.

## Граница гарантии шага — названа, не спрятана (замер 7)

В CI судья и подсудимый — один файл чекаута: саботаж ветвей, которыми судья ТРЕБУЕТ
красного (`:694` и соседний блок диагнозов), остаётся зелёным даже при полном прогоне
сам-тестов. Что держит границу: (а) `check:zones` на каждом пуше — правка
`scripts/verify_antiplacebo.sh` вне зоны действующего контракта красна (механизм
`user.name`); (б) чтение диффа раннера ролями при любой санкционированной правке;
(в) при открытии контракта, правящего раннер, судейство его пачки обязано включать ручной
полный прогон (тот же, что уже требует компенсация Н-103 перед done×4). Остаток —
cognitive-only; слова владельца не требует: инвариант 3 говорит об исполнении фикстур в CI,
а не о мета-неуязвимости судьи к само-саботажу — этой границы нет ни у одной самопроверки
по построению.

## Приёмка шага (ревьюеру следующего круга)

1. Шаг зелен на честном дереве — эталон замера 5: «фикстур: 23 · предъявлено красным: 23».
2. Шаг красен на дереве с саботажем, видимым честному судье, — эталон замера 6 (4 case).
3. `verify_ci_parity.sh` rc=0 при оплаченной записи `команда:` с причиной; запись
   соответствует канону residual (не красный флаг: имя `npm run check:antiplacebo`
   статично, индирекции нет).
4. Шапка `UNSCOPABLE_KEYS` не содержит утверждения о косвенном исполнении сам-тестов.

## Счёт сторон

Ревьюер прав по фактам целиком — замеры 1, 3, 4 из четырёх спорных воспроизведены без
расхождений; компенсация имплементера ложна. Арбитр добавил корневую причину отказа ключа
(замер 2) и границу самоприменения полного прогона (замер 7), сузившую заявку ревьюера
«ловят это ТОЛЬКО fixtures/verify_antiplacebo/» до «ловят при честном судье». По действию
принята развилка ревьюера №1 в уточнённой scoped-форме. Несогласие любой стороны
записывается сюда, решения не отменяет.
