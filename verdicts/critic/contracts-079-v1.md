## Независимые живые предъявления класса

Библиотека прочитана целиком. Поиск `^[a-z_]*\(\) \{` дал ровно четыре
определения: `_incr_plural` (:54), `incr_parse` (:72), `incr_fail` (:175),
`incr_finish` (:196). Новых функций на судимом HEAD нет.

Собственная проба не использовала генератор д6ф автора. Из исходной
библиотеки извлечён побайтовый блок от `incr_parse() {` до первой строки
`}` в первой колонке. В копию check_ids.sh он вставлен непосредственно
после единственной исполняемой source-строки lib_incr.sh. Выбрана
incr_parse, а не носители прошлых контрпримеров incr_finish/incr_fail.

1. **Частная incr_parse после source.**
   `bash fixtures/pokrytie_083_088_079/red_istochnik_incr_079.sh <клон> Р3-источник/check_ids --check-sub <копия-после-source.sh>`
   → rc 1; финализатор зелёный, маркер красный, родовой носитель сообщает:
   `КРАСНО: Р3-источник/check_ids/след: функция incr_parse не вызвана честным путём — грамматика из частной копии, не из lib_incr.sh`.
   Наблюдённый след содержит `_incr_plural incr_finish incr_fail`,
   отсутствует именно incr_parse. Итог: зелёных 1, красных 2.

2. **Та же побайтовая копия до source.**
   Аналогичная команда с `<копия-до-source.sh>` → rc 0,
   `red_istochnik_incr_079.sh: зелёных 3, красных 0`.
   Библиотека перекрывает мёртвое определение; это разрешённая граница
   :247–248, не пропущенный исполняемый частный источник.

3. **Одна из четырёх функций недостижима при любом входе.**
   В отдельной копии корня заменён единственный вызов
   `[ "$INCR_RC" -eq 0 ] || { incr_fail; exit 1; }`
   на `[ "$INCR_RC" -eq 0 ] || { exit 1; }` в check_ids.sh.
   Остались только определения/комментарии incr_fail, вызовов нет.
   Клетка запущена над этим корнем БЕЗ --check-sub, как честный вход:
   `bash <клетка> <корень-без-вызова> Р3-источник/check_ids` → rc 2,
   `NOT_IMPLEMENTED: Р3-источник/check_ids/след: функция incr_fail не вызвана честным путём на честном прогоне — недостижима входами (дрейф lib_incr.sh)`.
   Маркер и кеш-запись зелёные, но файл не возвращает ложный rc 0.

4. **Дополнительная проверка динамического множества.**
   В другой копии корня в lib_incr.sh добавлена пятая функция
   `incr_future_probe() {` с телом `:` и закрывающей `}`.
   Клетка без --check-sub → rc 2, тот же NOT_IMPLEMENTED по имени
   `incr_future_probe`. Набор действительно берётся из библиотеки
   на прогоне, не ограничен вручную сегодняшними четырьмя именами.

Все четыре исхода проверены исполняемой независимой пробой с проверкой
кода возврата и именованной строки, итог пробы rc 0. Это проверки
критерия заморозки, не правка или приёмка реализации барьеров.
