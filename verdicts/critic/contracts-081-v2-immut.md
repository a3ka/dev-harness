## Блокирующие находки

### Б7. I2 теряет фактический код возврата установщика

БЛОКИРУЕТ contracts/081-obshchij-git-konfig-strazh.md:378 — обязательное «тогда: rc 0» не проверяется названной батареей; проверяется успешность последнего присваивания внутри обёртки.
ОБХОД: кандидат с корректными предусловиями и установкой +i, корректным детектором и разделом README после успешной установки возвращает `exit 1`. Неизменённая батарея принимает всё дерево: `итог [MOCK]: зелёных=29 красных=0`, rc 0, включая строку I2 «оба предусловия → rc 0». Установщик при выполненных предусловиях всегда сообщает неуспех — обещанный успешный исход установки не реализован, а приёмка зелёная.

Причина в носителе критерия: `fixtures/ops_server/red_git_config_immut_081.sh:467–469`
заканчивает `irun` присваиванием `rc=$?`, которое само возвращает 0. В :490
`irun "$SANDBOX/i2"; irc=$?` забирает этот 0 вместо сохранённого кода субъекта.
Это тот же класс потери rc, который А-345 описывает для другой обёртки, но не
тот же конкретный обход, что Б1 первого круга: прежнее снятие атрибута теперь
действительно ловится.

Живой `bash -x` неизменённой батареи против кандидата показал непосредственно:

```text
+ out='COUNTEREXAMPLE: locked successfully, returning rc 1'
+ rc=1
+ irc=0
...
итог [MOCK]: зелёных=29 красных=0
traced-battery-rc=0
```

Требуется различить фактический rc установщика, не менять предмет/инвариант.
Наличие атрибута, отказ записи и отсутствие записанного значения в этом обходе
подлинные: дефект не маскируется отсутствием защиты или аварией кандидата.

### Б8. «Журнал пуст / chattr НЕ вызван» подменено отсутствием одной +i-строки

БЛОКИРУЕТ contracts/081-obshchij-git-konfig-strazh.md:374 — I1/I1b обещают отсутствие любого chattr до отказа по предусловиям (также И-2 :128–144), но батарея не проверяет пустоту журнала.
ОБХОД: на обоих путях отказа по отсутствию hooksPath / autoSetupMerge=false кандидат сначала исполняет `chattr -i "$M081/.git/config"`, затем печатает правильную причину и выходит 1; положительный путь остаётся корректным. Неизменённая батарея даёт 29 зелёных / 0 красных, rc 0 и печатает для I1/I1b «chattr не вызван». При этом предписанное «ДО любого chattr» нарушено: отказный путь сам снимает защиту вместо проверки только чтением.

Причина в носителе: `fixtures/ops_server/red_git_config_immut_081.sh:474,483`
проверяет только отсутствие строки `+i <целевой config>`. Строка `-i <тот же config>`
не запрещена и непустота журнала не замечается. Здесь не предлагается новый
класс защиты: именно отсутствие ЛЮБОГО вызова chattr и пустой журнал уже названы
в И-2 и в I1/I1b.

Собственный прогон мутанта (обе отказные ветки изменены, положительная не менялась):

```text

ок    I1b autoSetupMerge не false → rc 1 ДО chattr (chattr не вызван)
```
