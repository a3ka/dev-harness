## Независимое повторение insteadOf/pushurl

Одноразовая Python-проба извлекла без модификаций старый CORE и CORE с HEAD.
SHA-256 нового тела:
`e70b107fda2314ace195e32f9d473c7fa2f845382b0cf8441343447f5c5fd053`.
Новое тело — **носитель проб**, не предъявленная реализация 045. Эти проверки
не заменяют будущий implementer/adversary-круг.

Для каждой конфигурации созданы свои source, живой canonical.git и пустой
foreign.git. До пробы источник запушен в канон. Новый CORE вызывается через
`bash <new-core.sh> push origin main:<ref>` с ручкой канона; сверяются точный
stderr, rc1, пустой stdout, все refs и SHA-256 содержимого **каждого файла**
foreign.git с предвызовным снимком. Затем старое ядро вызывается на том же
входе как положительный контроль воспроизведения ущерба.

Фактический scratch:
`/tmp/dev-harness-verify/critic045second/tmp/critic045-replay.skuv0nbr`.
В следующих строках `$T` обозначает только этот напечатанный путь.

```text
insteadOf:
  config --get remote.origin.url = $T/insteadOf/canonical.git
  remote get-url origin          = $T/insteadOf/foreign.git
  remote get-url --push origin   = $T/insteadOf/foreign.git
  NEW rc=1
  gitw ОТКАЗ: URL origin не канонический: $T/insteadOf/foreign.git
  foreign.git: все файловые байты и refs неизменны
  OLD rc=0; main -> wip/rewrite
  refs/heads/wip/rewrite=c181a72ec6c491606f2c5fb6fb9c92c0efcb65a4=source HEAD

pushurl:
  config --get remote.origin.url = $T/pushurl/canonical.git
  remote get-url origin          = $T/pushurl/canonical.git
  remote get-url --push origin   = $T/pushurl/foreign.git
  NEW rc=1
  gitw ОТКАЗ: URL origin не канонический: $T/pushurl/foreign.git
  foreign.git: все файловые байты и refs неизменны
  OLD rc=0; main -> wip/injected
  refs/heads/wip/injected=10bafe9197d954736d51655582c722df31548335=source HEAD
```

Это различает защиту от случайного отсутствия upstream в батарейной топологии.
Обе исходные атаки с новым носителем получают именно F1, называющий фактического
получателя, а не только произвольный ненулевой код. Одноразовая проба завершилась
rc0; toy-репозитории удалены её finally-контекстом.
