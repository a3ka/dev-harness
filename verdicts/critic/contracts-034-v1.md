## Б1 закрыт: отказ переживает нулевую changed-выборку

Основание: `contracts/034-ranner-probe-only-i-autentichnost-zamera.md:70–77,112–118`.

Независимо воспроизведён контрпример A из первого круга: классификация probe-only корректна, селектор пропускает легальную probe-правку, но раннер сохраняет прежний ранний `MODE: none / exit 0`, стирающий накопленный отказ.

Обновлённый `red_katalog_ne_flagaetsa.sh` на A:

```text
ворота 1 (полный): rc 0
ворота 2 (scoped): rc 0
ворота 3 (--changed): rc 0
ОТКАЗ: ворота 4 — rc 0
  FAIL fixtures/stranaja: фикстура без барьера — она ничего не держит
  SCOPED: 0 задетых при резолвимом base — нечего гонять, зелёно
  MODE: none
```

Код всего предъявления — **1**, то есть прежний обход больше не принимается.

Обе формы отдельно исполнены прямым вызовом раннера. Для каждого входа нелегальный каталог включён в базовый коммит; `git diff --name-only BASE HEAD` содержит только `fixtures/probe_subject/red_probe.sh`:

| Вход вне диффа | Контрпример A | Честная модель |
|---|---:|---:|
| case-каталог без ключа и без маркера | 0, при напечатанном FAIL | 1, с тем же FAIL |
| тот же case-каталог с `.probe-only` | 0, при напечатанном FAIL | 1, с тем же FAIL |

Честная модель отличается от A сохранением накопленного отказа перед ранним выходом. Полное обновлённое предъявление на ней проходит, включая обе формы ворот 4.

Поскольку исходный A останавливает fail-fast предъявление на первой форме, дополнительно исполнена инструментальная модель, сохраняющая отказ первой формы, но теряющая отказ формы с маркером. Предъявление также вернуло 1 на воротах 4 с фактическим rc раннера 0. Тем самым проверена достижимость и различающая сила именно второй проверки, а не только первой.

## Б2 закрыт: полный прогон больше не выдаётся за нуль выбора

Таким образом ворота 5 отвергают именно прежний обход Б2 после успешного прохождения ворот 1–4.

Собственный прогон завершился:


Предъявление различающее, не вечнокрасное.
