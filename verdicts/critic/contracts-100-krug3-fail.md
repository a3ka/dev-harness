## Новая блокирующая находка

### Б9. И-11в проверяет чужое сообщение только на первой строке отчёта

БЛОКИРУЕТ contracts/100-doverennye-isklyucheniya-main-ci.md:310 — обещание «на КАЖДУЮ FAIL-строку» (:169) не удержано исполняемым критерием: единственный двухстрочный под-вход ставит чужой message первой FAIL-строке, но не отличает проверку только первого message от проверки всех.
ОБХОД: субъект first-report-message на основе CORE MODE=none проверяет path/message только первой FAIL-строки в порядке отчёта, затем выходит из внутреннего цикла; проверка общего числа аннотаций сохранена. Он удовлетворяет всей штатной семье. На конформном входе с двумя подписанными FAIL-строками и двумя failure-аннотациями с разрешённым path, где первая message правильна, а ВТОРАЯ чужая, выдаёт rc=0 и «находки 1/1» вместо обязательного «находка вне списка». Текущая И-11в предъявляет обратное расположение ошибки и этого субъекта пропускает.

Мутация общая, не проверяет имя клетки, конкретный путь, текст, SHA или порт:
после сравнения cn/ln в цикле аннотаций добавлен `break`; источник того же
цикла — строки fl в порядке отчёта вместо LC_ALL=C sort -u. Всё остальное
в MODE=none, включая общее nall==jfail и подсчёт хеша ВСЕХ FAIL-строк, сохранено.
Это обычная ошибка неполного обхода массива, не стаб, узнающий тест по данным.

Контрпример — неизменные И-11в FAIL-строки и запись списка:

```text
T1 = check:skills: FAIL: нет положительного контроля
T2 = check:skills: FAIL: второй случай case_42
annotation[0] = path fixtures/check_skills/, message T1
annotation[1] = path fixtures/check_skills/, message check:skills: FAIL: иная причина case_77 (чужой message)
```

Единственная дельта входа против И-11в — расположение чужого message:
`fixtures/check_skills/~$AP2VTO,fixtures/check_skills/`
заменено на
`fixtures/check_skills/,fixtures/check_skills/~$AP2VTO`.
Число строк, аннотаций, подписанный sha256, object, job, ключ и определения не меняются.

Живое встречное предъявление:

```text
MODE=none: subject_rc=1
 gitw ПРЕДПОЛЁТ-ОТКАЗ: PR-CI: находка вне списка: ap2/check:skills
first-report-message: subject_rc=0
 gitw ПРЕДПОЛЁТ: PR-CI допуск: wip/100/demo (8fd60dae5a7cbfd65bc954786bb68efbcbd248cc): jobs 12/12 исполнено, находки 1/1
```

Полный результат штатной семьи для этого мутанта приведён в разделе проверок.
Первый исследовательский вариант — остановка после первой ЛЕКСИКОГРАФИЧЕСКОЙ
строки без смены порядка — штатной И-11в пойман. Он не является основанием FAIL.
Б9 относится к реально непойманному варианту первого message В ПОРЯДКЕ ОТЧЁТА.

Минимально достаточное усиление — предъявить встречный порядок (первая аннотация
верна, вторая нет), сохранив позитив с обеими правильными; обход должен стать красным.
Менять решения арбитра, API или границу причин ради этого не требуется.
