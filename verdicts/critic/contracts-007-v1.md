## Фактические прогоны ci-ветви

Каждый временный корень содержал `scripts/verify_antiplacebo.sh`, поэтому проверки дошли до
ветви `ci`, а не завершились предварительным RC=2.

- Текущий реальный корень: `bash scripts/check_scoped_run.sh . ci; echo RC=$?` → `RC=1`.
  Реальный шаг без `--changed` красен.
- Shell-comment обход: строка
  `run: npm run check:antiplacebo # --changed ${{ github.event.before }}` → `RC=1`.
  Обход пойман: токены после первого `#` не засчитаны как исполняемые.
- Честная проводка: строка
  `run: npm run check:antiplacebo -- --changed ${{ github.event.before }}` → `RC=0`.
- Дополнительный вариант: исполняемая часть заканчивается на `--changed`, затем перед `#`
  стоит таб, а `${{ github.event.before }}` находится только в комментарии → `RC=1`.
  Наличие лишь одного из двух аргументов до shell-комментария не даёт зелёного.
