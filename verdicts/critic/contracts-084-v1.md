Прежнее «проверить только непустоту» больше не удовлетворяет приёмке: последующее расхождение блока ROADMAP не заменяет требуемый отказ разбора поля. Профиль гигиены также предъявляет `|` внутри трека.

### 2. Приоритет статусов на пересечениях — закрыто

Основание: `contracts/084-reestr-plana.md:99–103,321–324,344–351`.

Проверяется именно одновременное присутствие источников статуса, а не два раздельных мира:

- **с7**: frozen-пункт остаётся в ранее заполненном HANDOFF, затем получает строку закрытия; `check_plan` обязан назвать его закрытым следующим пунктом;
- **с8**: генератор обязан убрать этот пункт и допустить зависящего от него кандидата; сверяются весь блок и отдельно точные id выбранных строк;
- **д3**: frozen + closed даёт `закрыт без done`, а done + frozen + closed — раздел `done`; весь stdout сравнивается с независимым оракулом;
- **ф10**: frozen + закоммиченное закрытие исключает первую пару из открытых и позволяет заморозить 001 в следующей паре.

Порядок `done → frozen → закрыт без done` больше не совпадает с ожиданиями приёмки ни для выбора, ни для дайджеста, ни для расчёта пар freeze.

### 6. Состав первоначального переноса — закрыто

Основание: `contracts/084-reestr-plana.md:190–197,369–375`.

Ж6 больше не подменяется самосогласованностью `check_plan`.
