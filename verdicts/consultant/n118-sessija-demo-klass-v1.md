## 2. Оценка вариантов

### А: различение сборок полезно, предъявленный B1 не закрывает

Composition root — `app/index.tsx:17–25` и `(tabs)/[section].tsx`, общий адаптер app/onboarding-session.tsx, далее bootstrap/pilot-app.tsx. Features не выбирают транспорт/тестовую среду. Сборочный выбор — существующий alias @pilot/runtime в Metro/Jest, не __DEV__, NODE_ENV, principal или поле произвольного payload.

Статически встроенное Expo `process.env.EXPO_PUBLIC_API_MODE` описывает артефакт сборки. Сетевой Session не переписывает литерал неизменённого bundle; сборщик, JS-инъекция или подменённый APK — могут. PUBLIC-значение не секрет, подпись или серверная проверка прав. В Jest env читается Node при загрузке config; alias может переопределяться конфигурацией, а изменение env ПОСЛЕ выбора alias само по себе runtime не переключает. Состав поставки проверяется bundle-пробой обоих режимов, не одним if в hook.

Если нужен mode-предикат, он должен совпасть с режимами выбранного runtime: http; mock/unset/пустой по действующей default-конвенции; неизвестное — ошибка, не «любой не-http даёт W1A».
