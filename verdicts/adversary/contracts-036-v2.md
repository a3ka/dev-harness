БЛОКИРУЕТ — В3 точное сравнение автора снова обходится табуляцией в `%an`.

В `scripts/check_spec_ready.sh` фильтр собирает строки через `git log --pretty=format:'%H%x09%an'`, затем применяет `awk -F'\t' ... '$2 == role'`. Git допускает табуляцию в `user.name`; поэтому автор `implementer<TAB>evil` сериализуется как `<sha><TAB>implementer<TAB>evil`, а awk видит `$2 == "implementer"` и ошибочно принимает чужой коммит за коммит роли.

В toy-репозитории создана frozen `contracts/001-x.md` v1 с `ЗОНА implementer: scripts/foo.sh scripts/bar.sh`; затем `scripts/foo.sh` меняет автор `implementer<TAB>evil`; черновик снимает `scripts/foo.sh` и содержит формально валидное `СПАСЕНО implementer: <SHA> — move`. Прогон настоящего предмета:

```text
bash scripts/check_spec_ready.sh <toy-tab> contracts/001-x.md
rc=0
OK
```

Это тот же В3-класс: имя автора не равно роли, но его SHA принимается как покрытие переноса. Условие точного равенства `%an == role` не выполнено. Нужен формат, который не теряет байты имени (например, NUL-разделённые поля с соответствующим потребителем), либо явный именованный отказ имени автора с табуляцией до сопоставления.

БЛОКИРУЕТ — грамматика path-glob принимает выход из корня.

Заявленный `^[A-Za-z0-9._/*?-]+$` допускает `../`. В toy-корне нет подходящих файлов, но в соседнем каталоге создан единственный `outside.txt`; замер:

```text
замер: `printf '1\n'; : ../outside/*.txt` = 1 census ../outside/*.txt
```

прошёл настоящий гейт:

```text
rc=0
OK
```

Его M2 выполнил `cd <root>; files=( $glob )` и посчитал файл за пределами корня. Это не file-census дерева-кандидата, хотя контракт требует path-glob относительно корня и независимый пересчёт от корня. Грамматика должна отвергать сегмент `..` (в том числе `../`, `x/../`) до запуска M1/M2, либо M2 должен конструктивно ограничить развёртку корнем.

БЛОКИРУЕТ — M1 исполняется как авторский `bash -c` и может подделать M2, изменив дерево до независимого пересчёта.

Предмет запускает `timeout 60 bash -c "$cmd"` до M2. В чистом toy-корне без `*.txt` замер:

```text
замер: `touch fabricated.txt; printf '1\n'; : *.txt` = 1 census *.txt
```

дал:

```text
OK
fabricated=yes
```

Команда действительно использует глоб, но сначала создаёт единственный файл, который затем считает M2. Следовательно, две меры не независимы относительно исходного дерева: ложный census зелёный. Это именно M1-сторона проверенного обхода, а не повтор старой подстановки glob. Нужен снимок/пересчёт M2 до M1 либо изолированный read-only запуск M1 с M2 по неизменяемому кандидату.

ДОПОЛНИТЕЛЬНЫЙ ДЕФЕКТ — обещанный ASCII-фильтр зависит от locale. При `LANG=en_US.UTF-8` строка:

```text
замер: `printf '1\n'; : prøbes/*.sh` = 1 census prøbes/*.sh
```

в toy с `prøbes/a.sh` дала `rc=0; OK`, хотя комментарий реализации объявляет только ASCII. Тот же ввод при `LC_ALL=C` отвергнут именованно: `спек-гейт 036: census-глоб вне грамматики path-glob` (rc=1). Если ASCII — часть фикса, регулярное выражение должно выполняться в `LC_ALL=C` или проверяться побайтно. Этот дефект сам по себе не понадобился для FAIL: три обхода выше уже достаточны.
