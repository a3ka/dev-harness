## Найдены три зелёных обманных стаба

Во всех трёх ниже `config/ci_parity_exceptions.txt` содержал точное
`команда:`-исключение с полной причиной. Это нейтрализует только правило 6,
чтобы красность обязан был предъявить независимый инвариант 4 / fail-closed
грамматика, а не отсутствие пункта приёмки.

### 1. Вложенная shell-индирекция остаётся после единственной подстановки

Внешний legacy-шаг был:

```yaml
- env:
    ANTI_SCRIPT: $OTHER_SCRIPT
  run: npm run "$ANTI_SCRIPT" -- --changed legacy
```

Барьер вернул **`rc=0`**. `_literal_env_map` принимает значение
`$OTHER_SCRIPT` как литеральное, а `_resolve_npm_indirection` подставляет
только один раз: получается `npm run $OTHER_SCRIPT`, после чего второй
неразрешённый токен уже не анализируется. Точный `команда:`-канал закрывает
правило 6, `ANTI_TSV` не получает запуск, и проверка объявляет нарушение
отсутствующим.

Это прямо нарушает требование к3 для `VAR=$OTHER_VAR`: значение в командной
позиции не стало статическим именем скрипта и обязано дать безусловный
именованный отказ, а не легализоваться исключением.

### 2. Флаг npm до `run` скрывает реально исполняемый анти-плацебо-запуск

Стаб:

```yaml
- env:
    ANTI_SCRIPT: check:antiplacebo
  run: npm --silent run "$ANTI_SCRIPT" -- --changed legacy
```

с точным исключением команды дал **`rc=0`**. Регулярное выражение
`NPM_SCRIPT_VAR_RE` требует смежную форму `npm\s+run`, поэтому не видит
допустимый npm флаг до `run`; до `ANTI_TSV` команда не доходит.

Это не мёртвый текст: в отдельном минимальном `package.json` та же команда
была реально запущена и вернула:

```text
npm-flag-runtime: rc=0; stdout=anti-executed
```

Следовательно, CI исполнит скрытый `check:antiplacebo`, тогда как барьер с
разрешённой для правила 6 командой остаётся зелёным.

### 3. `${{ matrix.cmd }}` в имени скрипта легализуется двумя исключениями

В корректной matrix-джобе (запись include имела `shard`, `keys` и
`cmd: check:antiplacebo`) обычный шардный шаг был заменён на:

```yaml
run: npm run ${{ matrix.cmd }} -- --scope ${{ matrix.keys }}
```

Точные исключения для этой команды и для скрытого в ней
`check:antiplacebo` дали **`rc=0`**:

```text
workflow-команд: 2 · скриптов в приёмке: 3 · объявленных исключений: 3 ·
matrix-ключей: 2 · анти-плацебо-запусков: 0 · расхождений: 0
```

`_resolve_npm_indirection` намеренно не распознаёт `${{ ... }}` как shell
`$NAME`, но после этого не отказывает на контекстном имени. Команда не
нормализуется к `npm run check:antiplacebo`, поэтому анти-плацебо-запуск
исчезает из `ANTI_TSV`. Это нарушает фиксированную грамматику предмета:
имя скрипта обязано быть статичным, а matrix-шаблон допускается только в
аргументах `--scope`; контекстное имя должно быть fail-closed, без права
исключению правила 6 скрыть его.
