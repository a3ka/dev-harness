# Контракт 081 — адверсарий, круг 2: I3 против ложнозелёного self-check

Проверена только находка круга 1: мутант установщика, который успешно вызывает
`chattr +i`, но не выполняет install-time сверку `lsattr`, не должен выглядеть
успешным.

## Живые прогоны

1. Честный предмет:

   ```text
   IMMU_MOCK=1 bash fixtures/ops_server/red_git_config_immut_081.sh
   rc=0; итог [MOCK]: зелёных=30 красных=0
   ```

   В том числе I3 зелёная: `chattr rc 0 ∧ атрибут НЕ стоит → установщик
   отказывает rc 1 (self-check И-1)`.

2. Мутант круга 1: в одноразовом клоне временно удалён блок `lsattr`/`case`
   после `chattr +i` из `ops/server/install.sh`. Тот же прогон дал:

   ```text
   rc=1; итог [MOCK]: зелёных=29 красных=1
   красные клетки: I3
   КРАСНО I3 self-check обязан ловить «вызов успешен, атрибут не стоит» (rc=0; адверсарий 081-v1)
   ```

   Значит новая клетка различает именно нужный ложнозелёный мутант; остальные
   29 клеток остаются зелёными.

3. Вторичный контроль избирательности: временный мутант
   `scripts/check_git_config_immut.sh`, всегда завершающийся `rc=1`, не получает
   зелёный результат:

   ```text
   rc=1; итог [MOCK]: зелёных=22 красных=8
   красные клетки: D1 D2 D3 D4 D4b D5 D6 D7
   ```

После каждого временного мутанта исходник восстановлен; заключительный честный
прогон снова дал `rc=0`, `зелёных=30 красных=0`.

## Граница frozen-текста

Согласен: v+1 контракта не требуется. Хотя список сценариев ниже отдельно
называет I2, замороженный И-1 дословно требует, чтобы «шаг И-1 завершается
сверкой lsattr», и задаёт отказ при отсутствии `i`. I3 является прямой
исполняемой проверкой этого уже замороженного требования, а не новым
нормативным требованием.
