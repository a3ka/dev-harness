## Находка 1 — UTF-8 путь в зоне ложно красен

Toy строится штатным `fixtures/check_zones/_repo.sh` с единственной зоной:

```text
ЗОНА agent-x: scripts/
```

Положительные контроли чистого окна и `scripts/legal.sh` дают rc=0. Затем `agent-x` честно добавляет существующий git/Linux путь `scripts/é.sh`, лежащий под буквально объявленным префиксом. Обычный запуск барьера даёт:

```text
clean rc=0
ascii rc=0
utf8 rc=1
  FAIL коммит вне зоны: agent-x 2a01684e "scripts/\303\251.sh" — зона автора (объединение всех замороженных): scripts/
```

`git diff-tree --name-only` без NUL отдаёт C-quoted представление, но проверка сравнивает его с неэкранированным путём зоны. Это ложный красный категории (ii), не выход из зоны. Честный файл с LF в имени красится тем же механизмом.

Воспроизведение: `bash /tmp/dev-harness-verify/adversary040-v7/honest-paths.sh .` из корня предмета.

## Находка 2 — законный 40-hex путь становится ложным SHA-заголовком

Независимый toy объявляет точную зону и создаёт ровно такой top-level путь:

```text
ЗОНА agent-x: aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa
```

Это легальное имя Linux/git, не шаблон, не `..`, без пробелов и кавычек, оно в точности равно зоне. Старый per-commit запрос возвращает единственный верный путь:

```text
per-commit-path=aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa
```

Значит per-commit `git diff-tree -r --no-commit-id --name-only --no-renames <commit>` передал бы его точному сравнению зоны и принял бы. Batched-форма считает ту же строку заголовком блока по `/^[0-9a-f]{40}$/`, хотя она является данными. Completeness-guard красит полный честный поток:

```text
batched-guard-rc=1
ОТКАЗ: batched git diff-tree --stdin вернул неполный/искажённый поток (контракт 001, диапазон frozen/contracts/001/1..HEAD) — 0 SHA без заголовка путей, 0 SHA с более чем одним заголовком, 1 лишних заголовков без судимого SHA; список путей окна недостоверен.
```

Это не отказ инструмента и не пустой вход. Протокол без различителя типов отождествляет законную строку пути со служебным SHA. Находка одновременно категории (ii) и (iii).

Воспроизведение: `bash /tmp/dev-harness-verify/adversary040-v7/batched-header-collision.sh .` из корня предмета. Скрипт сам подтверждает совпадение per-commit пути с зоной, затем требует у текущей batched-проверки rc=1 и указанную причину.
