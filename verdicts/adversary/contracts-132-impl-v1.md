# Суд реализации 132 ekran-shablon

## Блокер 1 — маска hex-дайджеста скрывает размерный литерал

Состояние: честная пачка, построенная `probe.py`, с единственной добавкой в
`pack/batareja/red_ekrana.sh`:

```text
padding: 0000000000000001fa;
```

Прогон живого субъекта:

```text
python3 scripts/ekran_shablon.py --pack <pack> --repo <repo> --harness <H>
rc=0
KADR	Splash dark	0.783	0.600	tagline	OK
KADR	Splash light	0.782	0.600	tagline	OK
SHABLON	demo-vkhod	OK
```

Это представитель обещанного класса «число + любая буквенная единица 1–4
буквы» с ведущими нулями. Он обязан дать
`LITERAL_VNE_AUDITA`, но `RE_HEX_ZHIST` сначала маскирует всю обособленную
18-символьную hex-строку как дайджест: `fa` одновременно допустимая по
объявленной грамматике единица и буквы `a-f`. Тем самым нарушено прямое
требование Д-доп / инварианта 3: маска дайджеста не может скрывать число с
единицей. Батарея содержит только `...16px`, поэтому этот конфликт классов
не предъявляет.
