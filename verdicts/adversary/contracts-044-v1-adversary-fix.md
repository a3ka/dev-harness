ИТОГ: Б7б ЗАКРЫТ — на свежем SSH-клоне `origin`, HEAD `872132b`, все три прежних обхода теперь дают требуемые отказы, а честный draft-путь остаётся зелёным.

Проверка ограничена только Б7б и гигиеной `awk`; Б1–Б3 и прочие части 044 не пересматривались. Каждый toy был отдельным git-репозиторием с `origin/main`, строгой исходной зоной architect только `contracts/001-x.md`, а снимок жил вне toy. На каждом красном сценарии сверены: `--check` до = rc 1, именованный `--retake-bulk` отказ, SHA-256 файла снимка до/после одинаков, `--check` после = rc 1.

1. **Грамматика без дефиса.** При живом `id/CONTRACT/123` на самом коммите каждый из `contracts/123not-a-draft.md`, `contracts/123_not_a_draft.md` и `contracts/123` дал `1 → 1 → 1`. Отказ каждого — `переснятие-bulk не доказано: путь … не покрыт ни одной зоной`; базлайн не изменён. Следовательно, проверка четвёртого байта basename не позволяет прежнему расширению `contracts/<M>-*` до «первых трёх цифр».

2. **Post-freeze, рука А.** В toy был заморожен `contracts/123-original.md` (`frozen/contracts/123/1`), затем на незонированный `contracts/123-evil.md` переназначен `id/CONTRACT/123` прямо на его слитый commit. Результат также `1 → 1 → 1` с тем же именованным зонным отказом и неизменным снимком. Значит frozen-проверка действительно идёт до руки А, а не только в руке Б.

3. **Позитивный контроль.** Легитимный до-freeze `contracts/123-legit.md` с `id/CONTRACT/123` на своём слитом commit дал `1 → 0 → 0`; стенограмма назвала путь, автора `architect` и последний SHA. Сужение предиката не сломало разрешённый путь.

4. **Гигиена awk.** В отдельном private mount namespace в `/usr/bin/awk` был подставлен selective stub: zone-reader вызовы передавались настоящему `gawk`, а вызов извлечения `delta_paths` завершался rc 127. На живой дельте `docs/escape.md` `--retake-bulk` вернул rc 2 и именованное `NOT_IMPLEMENTED: извлечение delta_paths упало (awk/sort rc≠0)`; последующий `--check` остался rc 1. Ошибка producer больше не превращается в тихое переснятие нулевой дельты.

Живой запуск: временный adversary harness выполнил три path-варианта, post-freeze hand-A и позитивный контроль; отдельный harness для selective `awk` подтвердил rc 2. Нового обхода в заданной области не найдено.
