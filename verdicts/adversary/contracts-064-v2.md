## Различающая проба Б3

В одноразовой копии `/tmp/dev-harness-verify/adv064-first-home-b3` строка реализации была заменена ровно так:

```ts
return value.split('${HOME}').join(home)
```

→

```ts
return value.replace('${HOME}', home)
```

Это ошибочная реализация: она раскрывает только первое вхождение. На ней `bash fixtures/check_metering/red_home_raskrytie_064.sh` завершилась **rc 1**. ЗК и прежние С1--С4 были зелёными/пойманными, а единственная красная клетка была именно Б3:

```text
red  Б3: боль жива (ДВА ${HOME} в data_dir): репорт порта не в data_dir конфига: …/${HOME}/metering-064-…/.actual_port
ОТКАЗ: 064 боль жива: раскрыто только ПЕРВОЕ вхождение ${HOME} — стаб вердикта 0065a7f жив
```

Дополнительная дифференциация: на том же мутанте `npm run metering:selftest` дал rc 0 и `bash scripts/check_metering.sh` дал rc 0 (16 ветвей). Следовательно, прежние проверки пропускают этот конкретный обход, а Б3 его ловит исполнением; клетка не маскирует проблему общим отказом.
