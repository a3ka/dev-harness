## Находка: статический текст вместо исполнимого запуска

`ANTI_TSV` распознаёт анти-плацебо только по буквальному фрагменту
`npm run check:antiplacebo` после подстановки единственного alias `run-script`.
Это не покрывает две обычные shell-формы, которые честный GitHub Actions шаг
исполняет:

```yaml
- name: Legacy dynamic script name
  env:
    ANTI_SCRIPT: check:antiplacebo
  run: npm run "$ANTI_SCRIPT" -- --changed legacy
```

и

```yaml
- name: Legacy dynamic npm binary
  env:
    NPM_BIN: npm
  run: "$NPM_BIN" run check:antiplacebo -- --changed legacy
```

В обоих случаях тестовый `config/ci_parity_exceptions.txt` содержал ровно
соответствующую запись `команда:` с содержательной причиной. Поэтому правило 6
честно считало внешнюю форму объявленным исключением, а проверка
исключительности обязана была самостоятельно увидеть фактический запуск
`check:antiplacebo` вне matrix.

Исполненный контрпример с первой формой дал зелёный:

```text
$ bash /tmp/dev-harness-verify/adv-020-k2/attack_variable_name.sh
  ok   команда «npm run "$ANTI_SCRIPT" -- --changed legacy» ... объявленное исключение
workflow-команд: 3 · скриптов в приёмке: 3 · объявленных исключений: 2 ·
matrix-ключей: 4 · анти-плацебо-запусков: 1 · расхождений: 0
# rc=0
```

Второй сценарий в `/tmp/dev-harness-verify/adv-020-k2/attack_forms.sh` также
дал `variable-binary rc=0`. Это не синтаксическая фантазия: минимальные
контроли успешно исполнили реальные npm scripts:

```text
$ bash /tmp/dev-harness-verify/adv-020-k2/prove_variable_name.sh
variable-script-name-executed
# rc=0
$ bash /tmp/dev-harness-verify/adv-020-k2/prove_variable_npm.sh
variable-npm-executed
# rc=0
```

Следовательно, скрытый прежний `--changed`-запуск реально выполнится на
runner, хотя барьер объявит дерево зелёным. `env` является штатным полем шага
Actions, а `npm` уже гарантирован текущим `actions/setup-node@v4`; это
исполняемый обход, а не форма вне доступной CI-грамматики.

Фикс должен строить инвариант 4 из разбора исполняемых команд либо
fail-closed отвергать динамический бинарь/имя скрипта в `run:`. Текущее
исключение `команда:` не должно легализовать скрытый запуск
`check:antiplacebo` вне matrix. Вердикт не меняет предмет или проверку.
