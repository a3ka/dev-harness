## F2 — новый fail-open у `check_charter --okno`: rc `rev-list --count`

r7 добавил маркер окна, но его счётчик всё ещё маскирует ошибку:

```bash
OKNO_N=$(g rev-list --count "$OKNO_BASE..HEAD" 2>/dev/null) || OKNO_N=0
```

Живая проба: в игрушке после базы добавлен честный неуставной коммит
`src/a.txt`; настоящий `git rev-list --count <base>..HEAD` печатает `1`.
Перед `PATH` поставлен делегирующий wrapper `git`, возвращающий `127` только
для пары аргументов `rev-list --count`. Вызов
`check_charter.sh <repo> --okno <base>` завершился **rc=0**, напечатав:

```text
окно 086: <base>..HEAD (0 коммит.)
… все три уставных документа ok
honest-count=1
```

Следовательно, отказ инструмента выдан за успешный маркер с ложным `N=0`.
Это нарушает И-5: `N = rev-list --count`; также это не соответствует
заявленной r7 явной проверке rc каждого `rev-list`. В отличие от исходного
F1 конкретная безопасная проба не скрывает несанкционированную уставную
дельту (последующий список всё ещё судится), но она принимает ошибку
инструмента и публикует неверный обязательный результат проверки. Нужен
fail-closed rc `2` для ошибки именно счётчика, а не подстановка нуля.
