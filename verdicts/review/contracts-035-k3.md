## БЛОКЕР-1 (класс: подлог дословности) — «ДОСЛОВНО» не дословно: oid в 39 символов

Заголовок коммита утверждает «**ДОСЛОВНО** с разделёнными потоками». Блок
`DRY-RUN-STDERR-BEGIN…END` дословным НЕ является: третья строка несёт oid длиной
**39 hex** вместо 40 — в середине выпал символ `b`.

Моя мера — свежий прогон того же argv с разделёнными потоками, затем `diff` тела
стенограммы против захваченного stderr:

    $ cd /home/aka/Documents/dev-harness
    $ bash scripts/gc_agent_branches.sh --root /home/aka/Documents/dev-harness \
        2>/tmp/.../err.txt 1>/tmp/.../out.txt
    rc=0
    stdout lines: 0
    stderr lines: 6

    $ git log -1 --format=%B 009467b | sed -n '28,33p' 1>/tmp/.../steno_err.txt
    $ diff steno_err.txt err.txt
    3c3
    <   refs/heads/wip/035/architect  3eb0ca8d3a4d6854faab45efdfc31d7db8f0571
    ---
    >   refs/heads/wip/035/architect  3eb0ca8d3a4d6854faab45efdfc31bd7db8f0571
    diff_rc=1

    $ echo -n "3eb0ca8d3a4d6854faab45efdfc31d7db8f0571"  | wc -c   # тело коммита
    39
    $ echo -n "3eb0ca8d3a4d6854faab45efdfc31bd7db8f0571" | wc -c   # фактический вывод
    40
    $ git rev-parse refs/heads/wip/035/architect
    3eb0ca8d3a4d6854faab45efdfc31bd7db8f0571

Остальные 5 строк из 6 совпали побайтово; расходится ровно одна.

Почему это блокер, а не опечатка. Ровно ради запрета этого класса и заведён п.3(в):
«Стенограмма фиксируется из фактического прогона; пересказ коммита … исходную
стенограмму не заменяют». Выпавший символ в 40-hex идентификаторе — отпечаток
**ручного перенабора**, а не перенаправления потока: захваченный поток символов не
теряет. То есть сам дефект и есть свидетельство, что блок, объявленный дословным,
был набран заново. Дерево этот класс уже ело однажды — `c2e9421` («vse stroki
NNN→40hex»). Принять 39-символьный oid в документе, чья единственная функция —
быть сырьём, значит принять норму «дословно означает похоже».

обозначается «НЕ СОХРАНЕНО», а не восстанавливается по ожидаемому результату», то

где фиксируется происхождение записи; для случая «поздний перенос» контракт требует
«отдельным новым коммитом **с указанием происхождения**» — предмет и есть такой

Скобка «(исходный apply ~11:30 2026-09-20)» в шапке блока полем ИСТОЧНИК не является
и времён начала/окончания не даёт: это приблизительная отметка одного момента.
