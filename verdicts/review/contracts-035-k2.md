## БЛОКЕР-3 — census-стенограммы по-прежнему НЕТ: четыре поля CENSUS-* заняты данными жнеца

Шаблон, строки 179–186: `CENSUS-ARGV: <дословная команда, включая тело скрипта, если оно не
версионировано>`, `CENSUS-RC`, `CENSUS-STDOUT-BEGIN <полный сырой вывод, включая N/a/b и
классификацию верхнеуровневых записей>`, `CENSUS-STDERR`.

В теле `c86a920`:

    ARGV: --root /home/aka/Documents/dev-harness
    RC: 0
    CENSUS-ARGV: --root /home/aka/Documents/dev-harness
    CENSUS-RC: 0

`CENSUS-ARGV` побайтово равен `ARGV` жнеца тремя строками выше — это команда ЖНЕЦА, не
census; тела census-скрипта (он не версионирован) нет. `CENSUS-STDOUT` содержит вывод жнеца
и не содержит ни N, ни a, ни b, ни классификации верхнеуровневых записей. Числа 10/3/7
фигурируют только прозой внутри `ПОСЛЕ-APPLY` — без команды и без rc, то есть ровно в той
форме пересказа, которую п.3(в) объявляет не заменяющей стенограмму (строка 120).

Итог: блокер круга 1 («census-стенограммы нет») не снят — поля теперь присутствуют по имени,
но заполнены чужими данными. Формальное присутствие 20 заголовков ≠ исполнение шаблона.
