  - Своё предъявление через `World`:
    - OBJECT: mode метки 0o600 / 0o600 / 0o600 (засев / повтор / вытеснение);
    - мутант: mode метки 0o600 / 0o644 / 0o644, все rc 0.

  - Свойство И2 «Оба файла имеют mode 600» производство держит; риск — будущая регрессия `:289` при зелёном CI-шаге.
- [ ] **С-2 (implementer; совет). Диагностика `TRACE_SEED_NOT_READY` разорвана между потоками.**

  - Более простая форма: `{ printf 'TRACE_SEED_NOT_READY: '; cat "$raw.error"; } >&2`. Правку `:250` в этот предмет не вносить: это чужая зона (095).
