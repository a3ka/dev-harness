## Советы

- [ ] **С-1 (адресат architect → implementer). Имя ветки-схоронки в `sync-main` не всегда
  имеет форму `wip/<N>/<author|judge>-main-saved`.**
  - Фрагмент. `scripts/pre_judge.sh:150-188`, функция `save_branch_name`. Если в R нет
    локальных `wip/NNN/x`, она возвращает голое `main-saved`. Если такие ветки есть, берётся
    последняя по committerdate неосудейская `wip/*`. Это может быть ветка чужого предмета.
  - Замер. Probe P16: в чекауте без локальной wip-ветки готовая команда равна
    `git -C "<R>" branch main-saved <tip> && git -C "<R>" reset --hard origin/main`. Probe P9:
    при единственной `wip/301/backend` имя `wip/301/backend-main-saved` выбрано верно, а
    команда, исполненная как есть, сохранила tip и вернула main к origin/main.
  - Обязательство. В §Предмет форма `wip/<N>/<author|judge>-main-saved` записана, но у
    `sync-main` по грамматике есть только вход `--repo`, источника N у неё нет. Модель
    `reference.py` имя хардкодит. Само свойство безопасности соблюдается: tip сохраняется до
    reset, автосброса нет. Поэтому это совет. Закрыть можно так: v+1 контракта называет
    источник N (например, `--branch` у sync-main), либо fallback отказывает именованно
    вместо имени вне `wip/`.

- [ ] **С-2 (адресат orchestrator/architect). Барьер `scripts/pre_judge.sh` без
  `fixtures/pre_judge/case_*.sh`.**
  - Фрагмент. В шапке `scripts/pre_judge.sh:15` стоит «Коды возврата:», поэтому
    verify_antiplacebo считает файл барьером. Замер: `verify_antiplacebo.sh --scope
    pre_judge` → `FAIL pre_judge.sh: нет фикстур — ожидается fixtures/pre_judge/case_*.sh`,
    rc 1.
  - Почему совет. Красное доказательство дано исполняемой батареей
    `fixtures/dver_pered_kritikom/predverie_172` (`--stabs`: 12 из 12 caught). Зона
    implementer не содержит `fixtures/pre_judge/`. По моему подсчёту на дереве OBJECT тот же
    приём уже у 27 из 72 прочих барьеров (`gen_ci_steps`, `land_project`, `ci_klass` …). В
    CI-шардах antiplacebo ключа `pre_judge` нет. Что делать, решает владелец класса:
    оставить как есть или завести правило для guard'ов контрактных батарей.
