  `Set-Cookie: sid=SETCOOKIESECRET123` в sink попадает `"set-cookie": ["sid=SETCOOKIESECRET123; …"]`. Паттерн `set-cookie\s*:` в JSON
  никогда не срабатывает: между ключом и `:` стоит `"`. Многозначный `cookie: a=1; session=SECRET` → `"[REDACTED] session=MULTICOOKIESECRET"`.
  Экранированная форма `{\"cookie\":\"X\"}` в теле → `\"cookie\":[REDACTED]"X\"`: секрет остаётся в sink, файл не парсится.
  Текст `Set-Cookie: v` в теле съедается `[^\n]+` до конца строки вместе с закрывающей кавычкой, файл не парсится. Массив
  `cookie: ['…']` → `"cookie": [REDACTED]`, файл не парсится. Это тот же класс, что r5 снял для bearer, только для cookie/set-cookie.
  Обход: HARNESS_PII_GUARD подаёт один cookie без `;` и только в sync-ветку; мутант M6 (паттерн set-cookie удалён) зелёный 37/37.
