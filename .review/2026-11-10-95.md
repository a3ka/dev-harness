## Блок

- [ ] **Б-1 (адресат implementer). Предикат кодового предмета инертен на реальных контрактах.**
  - Фрагмент. `scripts/make_task.sh:876`: `printf '%s\n' "$CBYTES" | grep -Eiq '^КЛАСС ЗАДАЧИ: кодовый$'`.
  - Обязательство. §Предмет: «Кодовый предмет — отдельная строка `КЛАСС ЗАДАЧИ: кодовый` в фактически выбранном контракте». §Модель угроз, ЗАЩИЩАЕТ п.1: «от молчаливой выдачи кодового задания проекта с архитектурой без описания выбранного компонента». В самом контракте 170 строка класса записана как `КЛАСС ЗАДАЧИ: кодовый.` Предикат не признаёт кодовым даже его.
  - Замер. Complior-back (059815e, каталог `architecture/` есть): 25 файлов с кодовой строкой класса, совпадений с `^…(кодовый|КОДОВЫЙ)$` — 0. Реальные формы: `КЛАСС ЗАДАЧИ: КОДОВЫЙ (…)`, `…; …`, `кодовый.`, `кодовый — …`. В харнессе в `contracts/` таких строк 35, совпадений тоже 0. В мире семьи с байт-копиями этих форм OBJECT отдаёт rc 0 и пак без брифа: 4 из 4 форм с хвостом. Под `LC_ALL=C` форма `КЛАСС ЗАДАЧИ: КОДОВЫЙ` даёт rc 0, потому что `-i` не сворачивает кириллицу.
  - Более простая форма. `grep -Eiq '^КЛАСС ЗАДАЧИ:[[:space:]]*(кодовый|КОДОВЫЙ)([^[:alnum:]_]|$)'` проходит 19/19 клеток семьи (`probe.py --repo fix` rc 0), включая `document`. Все формы с хвостом и `LC_ALL=C` дают `ARCH_COMPONENT_NET`.
  - Что закрывает. Узнавать строку класса по значению до разделителя, без привязки к локали. Регресс-клетку на реальные формы может добавить только architect (см. С-1).

- [ ] **Б-2 (адресат implementer). `ARCH_COMPONENT_ID` срабатывает после запуска npm.**
  - Фрагмент. `scripts/make_task.sh:847-853`: `case` проверки ID стоит внутри `while`, в котором вызывается npm.
  - Обязательство. §Предмет: «Неконформный список отказывает `ОТКАЗ: ARCH_COMPONENT_ID:` до запуска npm».
  - Замер (npm-обёртка пишет argv в лог). `api.identity,../x`, `api.identity,bad/x`, `api.identity,-x` → по 1 вызову `npm --prefix …/architecture run brief -- --compact --component api.identity` до отказа. Сами отказы верны: rc 1, stdout пуст, первая строка `ОТКАЗ: ARCH_COMPONENT_ID: …`. Значит, проектная команда успевает исполниться, а её побочные действия — произойти.
  - Более простая форма. Отдельный цикл проверки всех ID до первого npm. Он проходит 19/19 клеток семьи, а на тех же входах даёт `npm_calls=0`.
