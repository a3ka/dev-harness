## Блокирующие

- [ ] **R124-1 (implementer · `scripts/push_product.sh:66-70`, г2; комментарий стр. 66-67 сам обещает «ни хвоста `.` … у сегмента»).** Дверь пропускает ветку, у которой
  сегмент в середине пути оканчивается на `.`. Контракт 124/1 г2 требует: «без хвоста `.`/`.lock` у
  сегмента… иначе „ветка вне грамматики: …“». Дверь проверяет `refs/*|*..*|*.|*.lock|*.lock/*`. Хвост `.`
  ловится только у последнего сегмента, промежуточный `*./*` не ловится. Репро (`repro.sh`, случай
  «АЛФАВИТ г2 ветка: foo./bar»): `--branch foo./bar` даёт rc 0
  `push_product ОК: a3ka/Complior-mob foo./bar … PR …/pull/1 создан` и один push-вызов git в следе двойника.
  Ожидалось rc 1 «ветка вне грамматики: foo./bar» без push. Настоящий git такой ref принимает
  (`git check-ref-format refs/heads/foo./bar` → rc 0), поэтому ничего не ломается, но замкнутый алфавит
  контракта нарушен. Исправление в ЗОНЕ: добавить `*./*` к тому же `case`.
- [ ] **R124-2 (implementer · `scripts/push_product.sh:125-127`, г7; инвариант 1, ЗАЩИЩАЕТ п.1/п.2).**
  Цель push можно переписать из `.git/config` клона, и тогда дверь пушит мимо канона профиля, в том числе
  в харнесс в обход г5. Дверь передаёт git канон как URL, а git применяет к нему `url.<X>.insteadOf` и
  `url.<X>.pushInsteadOf` из конфига клона. Сбрасывается только `credential.helper`. Репро на НАСТОЯЩЕМ git
  (двойник URL подменяет сам, поэтому для этого случая его в PATH нет):
  - `git -C <клон> config url.<bare dev-harness>.insteadOf https://github.com/a3ka/Complior-mob.git`
    → в мире появился `dev-harness.git refs/heads/rev124/proba <sha>`; дверь rc 1 только на г8 («PR не
    создан»), push уже прошёл;
  - `url.<bare Complior-back>.pushInsteadOf=<канон mob>` → `Complior-back.git refs/heads/rev124/proba <sha>`.

  Такой вход конформен по §Демаркация: профиль резолвится, канон https GitHub не харнесса, а конфиг клона
  демаркация не исключает. В дереве этот класс уже известен: `scripts/gitw:464-487` (критик 045-Б2)
  специально раскрывает insteadOf. Есть более простая форма внутри алфавита г7: до вызова push отказать
  «push отказан: …», если git в клоне видит хоть один ключ `url.*.insteadof`/`url.*.pushinsteadof`
  (`git -C <клон> config --get-regexp '^url\.'` непуст). Строки приёмки она проходит: на мире батареи
  таких ключей нет.
